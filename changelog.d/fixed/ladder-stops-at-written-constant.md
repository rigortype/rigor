- **[inference]** A constant read inside a namespace or subclass now stops at a same-named constant another file assigns, as Ruby does, even when Rigor does not carry that value across files (a Hash, an Array, a method call), instead of falling through to an outer constant: with `LIMIT = 5` at the top level and `module App; LIMIT = { n: 1 }; end` elsewhere, `LIMIT.fetch(:n)` inside `App` no longer reports ``undefined method `fetch' for 5``. ([#1290](https://github.com/rigortype/rigor/issues/1290), [#1301](https://github.com/rigortype/rigor/pull/1301))
