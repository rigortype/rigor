- **[inference]** A constant compound write — `H ||= x`, `H &&= x`, `H += x` and their `Conf::H` path forms — is now typed as the value it stores when the constant is bound in the same file, by a class or module, or in RBS, so `H = { x: 1 }; v = (H ||= 0); v[:x]` no longer reports `Integer#[]` on correct code; a constant bound to a value Rigor cannot type makes the write untyped, as a variable does, and a constant with no binding in sight keeps the memoizing `||=` reading. ([#1243](https://github.com/rigortype/rigor/pull/1243))
