- **[inference]** A `refine X do … end` written in a module's `def self.x`, or in a `def` inside its `class << self`, is now recorded as that module's refinement of `X`, so `M.setup; using M; "a".yy` no longer reports `call.undefined-method` and types from the refine body. It no longer makes `M` opaque either: `"a".zz` under `using M` is still reported, and the checks and calls under it no longer decline or type as `Dynamic[top]`. ([#1749](https://github.com/rigortype/rigor/issues/1749), [#1835](https://github.com/rigortype/rigor/pull/1835))
