- **[inference]** A block whose whole body is a memoizing index `||=` on a captured hash or array — `cache = {}; [1, 2].find { |e| (cache[:first] ||= e) == 2 }` — no longer folds each position to its own element, so `find` answers `1 | 2 | nil` instead of `2` and `found == 2` no longer reports a false `flow.always-truthy-condition`; the same holds over a Range receiver, an instance-variable hash and `transform_values`.
