- **[inference]** A `def` whose parameters are laid out differently from its RBS signature no longer binds a parameter to another parameter's declared type, so `def opt(x = 0, y = "")` under `(Integer x, ?String y)` no longer reads `x` as `String` and reports a false `undefined method`. ([#2768](https://github.com/rigortype/rigor/pull/2768))
  - Positional parameters now match by position across required and optional ones, a `*rest` binds only when the `def` has every declared leading positional, and a `**opts` only when it names every declared keyword; any other parameter stays untyped.
