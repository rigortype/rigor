- **[config]** `rigor check` now warns when a `signature_paths:` entry loads a bundled plugin's own `sig/` while `plugins:` does not name that plugin — the RBS arrives without the manifest, so the classes the plugin declares only partially on purpose are read as complete and calls your code really defines are reported as undefined. The warning names the plugin and the one edit that fixes it; it does not change the diagnostics themselves, which stay until [#660](https://github.com/rigortype/rigor/issues/660) settles where open-receiver membership belongs ([#697](https://github.com/rigortype/rigor/issues/697), [#902](https://github.com/rigortype/rigor/pull/902)).
