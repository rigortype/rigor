- **[engine]** A write to a global the interpreter sets, such as `$VERBOSE = true` or `$stdout = StringIO.new`, now widens its declared type in the file's methods instead of replacing it, so `warn "x" if $VERBOSE` is no longer reported as always truthy; a report that rested only on the written type, such as `$stdout.reopen(STDOUT)` after `$stdout = StringIO.new`, is no longer made.
