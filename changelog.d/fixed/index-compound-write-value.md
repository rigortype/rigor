- **[inference]** `h[k] += v`, `h[k] ||= v` and `h[k] &&= v` used as a value — a block's or method's result, or a method argument — now type as the value they store instead of their right-hand side, so with `counts = Hash.new(0)`, `r = words.map { |w| counts[w] += 1 }` no longer reads `[1, 1, 1]` and `r.last == 1` no longer draws a false `flow.always-truthy-condition`; a `+=` on a slot Rigor knows nothing about now reads as `untyped` rather than the increment, while a memoizing `cache[key] ||= build` on such a slot still reads as `build`.
