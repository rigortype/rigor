- **[engine]** A `return` inside a block its call may run more than once (`each`, `times`, `loop`, …) that only a later run reaches — `seen = 0; items.each { return false if (seen += 1) > 3 }; true` — now joins the enclosing method's inferred return type, so a caller's condition on the result is no longer reported by `flow.always-truthy-condition` on correct code.
