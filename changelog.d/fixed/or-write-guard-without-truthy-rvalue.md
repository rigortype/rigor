- **[inference]** A `||=` on an instance, class, global or local variable nothing visibly assigned no longer takes its right-hand side as the value when that side can never be truthy: `def self.settings = (@settings ||= raise("boot first"))` reads as whatever set `@settings` rather than `bot`, so `rigor sig-gen` no longer declares `def self.settings: () -> bot`, and `@verbose ||= false` reads `false` or the unseen value instead of `false` alone. An instance variable that only such a guard writes is no longer assumed `nil` in the class's other methods, so `attr_writer :token` beside `def token = (@token ||= raise "unset")` no longer reports `@token.length` as a call on `nil` or gets `def token=: (nil) -> nil` from `rigor sig-gen`. A memoizing `@default ||= new` keeps its `App` type. ([#1338](https://github.com/rigortype/rigor/pull/1338))
