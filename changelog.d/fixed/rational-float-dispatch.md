- **[inference]** Arithmetic between Ruby's core numbers now types as the class Ruby returns when the argument's class is known and the RBS declares an overload for it. `Rational` `+`, `-`, `/`, `modulo`, `remainder` and `quo` by a `Float` type as `Float` rather than `Rational`. `Float` and `Rational` operators with a `Complex` argument type as `Complex` rather than `Float`, `Rational` or `Numeric`. `Integer#%`, `#modulo`, `#remainder`, `#quo` and `#divmod` by a `Float` or `Rational`, `Integer#quo(Complex)`, and `Float#%` and `Rational#%` name that class rather than `Numeric`. With the `bigdecimal` signatures loaded, `Integer`, `Float` and `Rational` `+`, `-`, `*` and `/` by a `BigDecimal` type as `BigDecimal`, as Ruby does, rather than as the receiver's class. An overload the RBS declares for the argument's own class now wins over a receiver's `(Numeric)` overload declared after it. ([#1348](https://github.com/rigortype/rigor/pull/1348))
