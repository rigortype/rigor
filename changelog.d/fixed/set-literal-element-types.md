- **[inference]** `Set[x, y]` and `Set.new(array)` over non-constant members now carry their element type (`Set[Array[Symbol]]`, `Set[String]`) instead of `Set[Dynamic[top]]`, `.freeze` and `.dup` keep it, and `Set.new(enum) { ... }` no longer folds to the argument's own elements, which the block replaces ([#2278](https://github.com/rigortype/rigor/issues/2278)). `rigor sig-gen` still writes `Set[untyped]` for every Set.
