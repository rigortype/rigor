- **[effects]** `Hash#compare_by_identity` and `Hash#rehash` now count as receiver mutations, so `rigor effects` labels a method that calls one on a hash it does not own with `mutate.*` instead of reading it as effect-free; with `effects.check` enabled a `%a{pure}` method that does so reports `effect.envelope-exceeded` (a committed effect snapshot may need regenerating). [#1292](https://github.com/rigortype/rigor/pull/1292)
  - **[effects]** A mutating call whose receiver is itself a fresh allocation (`{}.compare_by_identity`, `[].push(x)`, `Hash.new.merge!(h)`) now reads as `mutate.local` instead of an `unknown-ownership` taint, so a method that builds an identity hash stays exhaustive and `%a{pure}`-compatible.
