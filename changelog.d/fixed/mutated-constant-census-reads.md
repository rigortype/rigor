- **[inference]** A constant or class variable holding a hash or array that the file mutates no longer reads its literal contents as the only possible values, so `H = { a: 1 }; H.default = 0; H[:b] == 0`, `T[:b] = 2; T[:b] == 2` and `A << 2; A.last == 2` no longer fold always-falsey, `T[:a] = "x"; T[:a].upcase` no longer reports an undefined method on `1`, and `rigor sig-gen` no longer writes a stale literal (`-> "x"`, `-> Array[:a]`) as the return type of a method that reads such a constant. [#1291](https://github.com/rigortype/rigor/pull/1291)
