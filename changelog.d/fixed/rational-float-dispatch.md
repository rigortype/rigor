- **[inference]** Arithmetic between Ruby's core numbers now takes the result class Ruby returns when the argument's class is known: `Rational + Float` and `Rational - Float` type as `Float` rather than `Rational`, and `Float * Complex` and `Rational / Complex` as `Complex`. The selector no longer lets a receiver's `(Numeric)` overload take an argument that an earlier, more specific `(Float)` or `(Complex)` overload in the RBS declares. ([#1348](https://github.com/rigortype/rigor/pull/1348))
