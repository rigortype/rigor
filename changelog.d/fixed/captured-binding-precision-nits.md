- **[inference]** A block parameter (or lambda parameter or block-local) that shares a captured local's name no longer counts as a reassignment of the outer local, so `a = [1]; [1, 2].map { |k| [[]].each { |a| a = k }; a.first }` types `[1, 1]` rather than `[Dynamic[top], Dynamic[top]]`, and an escaping block such as `Thread.new { [1].each { |x| x = nil } }` no longer drops the outer `x`'s narrowing. ([#1279](https://github.com/rigortype/rigor/pull/1279))
