- **[engine]** Rigor now discovers a gem's own `sig/` when the gem is installed from a `git:` source, not only when it comes from RubyGems, so a fork's hand-written or generated signatures are picked up the same way a published gem's are instead of every reference to it silently typing `untyped`.
