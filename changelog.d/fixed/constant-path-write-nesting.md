- **[engine]** A constant assigned through a path inside a namespace — `Holder::DEFAULT = Post` written in `module Admin` — is now filed under the namespace that spelling resolves to and typed with the enclosing namespace in scope, so reads spelled either `Holder::DEFAULT` or `Admin::Holder::DEFAULT` get the right class instead of an unrelated top-level one or no answer at all, and `self::DEFAULT = Post` is filed under the enclosing namespace the same way; the same assignment at the top level or through `::Holder` is unchanged, and one written on a runtime receiver (`klass::DEFAULT = …`) no longer records its value under the bare trailing name it used to be guessed into. ([#690](https://github.com/rigortype/rigor/issues/690), [#706](https://github.com/rigortype/rigor/pull/706))
