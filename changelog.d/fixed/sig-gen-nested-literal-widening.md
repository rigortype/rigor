- **[rigor sig-gen]** Over a `-> untyped` declared in `sig/`, `rigor sig-gen` now widens a literal nested in a tuple, a record or a type argument as it does a top-level one (`[1, "a"]` is written `[Integer, String]`, `{ a: 1 }` as `{ a: Integer }`), so a subclass override returning other values of the same shape no longer reports `def.override-return-widened` ([#2173](https://github.com/rigortype/rigor/pull/2173)).
