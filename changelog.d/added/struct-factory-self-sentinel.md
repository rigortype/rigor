- **[engine]** A `Struct.new(:text) do def shout; text.upcase; end end` method called on a struct whose members are known now types its body's member reads instead of answering `untyped` — the receiverless `text` read folds to the caller's value, so the method's return type does too, and a body that could have changed a member before reading it (its own setter, a call to one that sets, or letting `self` escape) still declines. ([#525](https://github.com/rigortype/rigor/issues/525))
