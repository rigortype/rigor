- **[plugins]** `rigor-activerecord` no longer switches itself off on a project that ships raw migrations without a committed `db/schema.rb` — it now types table names, finders, scopes and associations from the model source alone and stands down only the column-dependent checks, disclosing the reduced mode at `info` instead of `warning`. ([#569](https://github.com/rigortype/rigor/issues/569), [#576](https://github.com/rigortype/rigor/pull/576))
  - `Model.table_name` now types as `String`, and as the exact table name when your source declares one with `self.table_name = "…"` (inherited down an STI chain, unless something in that chain computes the name at runtime); a name derived by pluralizing the class is never pinned, because a matching table in the schema can belong to another model. `Model.quoted_table_name` types as `String`, since the quoting is up to the database adapter. ([#569](https://github.com/rigortype/rigor/issues/569), [#576](https://github.com/rigortype/rigor/pull/576))
