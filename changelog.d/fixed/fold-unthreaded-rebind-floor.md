- **[inference]** A block that updates an outer counter, flag, instance variable, class variable or global no longer has its value typed as if every call saw the first iteration's binding — so `xs.all? { seen += 1; seen == 1 }`, `xs.find { seen += 1; seen == 2 }` and `[1, 2].find { |e| seen ||= 0; (seen += 1) == 2 }` stop drawing always-truthy / always-falsey warnings, and `transform_keys` keeps every key such a block can choose.
