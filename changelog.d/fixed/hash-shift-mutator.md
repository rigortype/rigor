- **[inference]** `Hash#shift` now widens a literal hash's type the way `delete` does, so `k = { a: 1 }; k.shift` no longer keeps `{ a: 1 }` and `k.size == 1` no longer reports an always-truthy condition; a `non-empty-hash` refinement is likewise dropped after a `shift`. ([#1253](https://github.com/rigortype/rigor/pull/1253))
  - **[effects]** `Hash#shift` now counts as a receiver mutation, as `delete` already did: `rigor effects` labels a method that shifts a hash it does not own with `mutate.*`, and with `effects.check` enabled a `%a{pure}` method that does so reports `effect.envelope-exceeded` (a committed effect snapshot may need regenerating).
