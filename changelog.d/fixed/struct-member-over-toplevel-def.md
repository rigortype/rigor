- **[engine]** A method a class defines itself — a `Struct.new` / `Data.define` member accessor, an `attr_reader`, an inherited or included `def`, an RBS-declared method — is no longer shadowed by an unrelated top-level `def` of the same name, which typed the call as the top-level helper's return and could report a wrong-type error such as `undefined method 'upcase' for nil` on correct code. ([#618](https://github.com/rigortype/rigor/issues/618))
