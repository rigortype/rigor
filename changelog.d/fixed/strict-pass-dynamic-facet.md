- **[inference]** A call whose argument Rigor only partly knows (such as `Integer(v)` or `Float(v)` on an untyped `v`) now picks the RBS overload for the argument's class instead of the receiver's own: `1 + Float(v)` types as `Float` rather than `Integer`, and with `def add: (Integer) -> Integer | (Money) -> Money` in `sig/`, `money.add(Integer(v)).even?` no longer reports `call.undefined-method`.
