- **[types]** Integer ranges are now spelled with the Ruby range literal that covers them, `Integer[1..10]` / `Integer[0..]` / `Integer[..-1]`, both in diagnostics and in `%a{rigor:v1:…}` annotations (`Integer[1...10]`, `Integer[1..]`, `Integer[..10]` and `Integer[nil..nil]` are accepted, an empty range declines); the PHPStan-style `int<min, max>` still parses as a deprecated alias but is no longer displayed, and the universal range displays as `Integer` instead of `int` ([ADR-109](https://github.com/rigortype/rigor/blob/master/docs/adr/109-ruby-native-range-notation.md), [#830](https://github.com/rigortype/rigor/pull/830)).
