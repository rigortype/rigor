- **[inference]** A counter or flag that a block rebinds no longer reads as its first-iteration value when the receiver is untyped or a project class outside Rigor's iterator catalogue. `items.all? { |x| seen += 1; seen == 1 }` on an untyped `items`, or `find` on a project class that includes `Enumerable`, no longer reports its result as always truthy or always falsey. A project class whose ancestry reaches `Enumerable` or a core collection now also keeps a block's rebinds after the call. [#1420](https://github.com/rigortype/rigor/pull/1420)
