- **[engine]** A call inside an RSpec-style block no longer starts binding to a same-named top-level `def` from an unrelated file as soon as the block contains an `if` — the confidence rule that declines such a bind survived only until the first branch in the block, so a matcher like `expect { … }.to output(/x/)` was captured by your own `def output` and reported a bogus error on the chain. ([#600](https://github.com/rigortype/rigor/issues/600), [#603](https://github.com/rigortype/rigor/pull/603))
