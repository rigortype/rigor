- **[plugins]** `Rigor::Plugin::IoBoundary#glob(root, pattern)` returns the paths a `Dir.glob` pattern matches under `root`, `**` included, and records which paths match, so a cache built on the run reads stale when a match appears or disappears. A touch or an edit does not move that row: a plugin that depends on a match's content reads it with `#read_file`. A pattern that can leave `root` (a `..` segment, a brace or a backslash) is refused. ([#1802](https://github.com/rigortype/rigor/pull/1802))
