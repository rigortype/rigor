- **[inference]** A `map` / `select` / `find` block over an array literal, or a `transform_values` / `transform_keys` block over a hash whose keys are statically known, no longer reads a value the block mutates in place at its pre-mutation contents when the call sits inside another block that assigns a local the call uses: after `r = m.synchronize do w = v; { x: [], y: [] }.transform_values { |a| a << w; a } end`, `r` types `{ x: Dynamic[top], y: Dynamic[top] }` instead of `{ x: [], y: [] }`, so `r[:x].first + 1` is no longer reported as a call on `nil`. ([#1213](https://github.com/rigortype/rigor/pull/1213))
