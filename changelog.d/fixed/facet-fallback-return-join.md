- **[engine]** A call passing an argument that is `Dynamic` over one or two sealed types (`fmt(n)` with `n : Dynamic[Integer]`) no longer takes the first overload's return when that argument cannot pick an overload. It joins the returns of every overload the argument may reach, so `undefined method 'even?' for String` no longer fires on correct code. Such calls to methods whose overloads Rigor cannot tell apart (`Complex(Integer(v), 1)`) now type as `Dynamic[...]` instead of one overload's return. ([#1798](https://github.com/rigortype/rigor/pull/1798))
