- **[inference]** A block that reassigns or mutates a variable from outside it is no longer typed from its first iteration alone on calls such as `map`, `find` or `each`: `i = 0; arr.map { i += 1; i == 1 }` now types `Array[bool]` instead of `Array[true]`, and `seen = 0; arr.find { seen += 1; seen == 2 }` is no longer folded to `nil` and reported as an always-falsey condition. ([#1226](https://github.com/rigortype/rigor/pull/1226))
