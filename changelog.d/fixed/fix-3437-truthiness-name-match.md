- **[inference]** `flow.always-truthy-condition` is no longer reported on a constant another file declares when the reading file assigns a constant of the same name in a namespace the read does not reach, so `if MODE == :production` at the top level stays quiet in a file that only assigns `M::MODE`. ([#3440](https://github.com/rigortype/rigor/pull/3440), [#3437](https://github.com/rigortype/rigor/issues/3437))
  - A file's own constant is now recognised by the names the reference can resolve to where it is written, through the enclosing modules and the enclosing class's ancestors, and `::MODE` always reads the top-level constant.
  - The same holds when the constant is first copied into a local, an instance variable or another constant, and when the condition calls a project method that reads it.
