- **[engine]** A module function's instance copy is now recorded private, as Ruby makes it, so a class that includes a `module_function` module and overrides one of its methods privately no longer reports `def.override-visibility-reduced`, and `rigor sig-gen` no longer writes a public `def x` for `module_function :x` or `module_function def x` (it emits that private method only with `--include-private`). A singleton-side call to a method whose instance copy is private (`M.two(1)` with `def self.two(a, b)` beside `private def two(a, b)`) now reports `call.wrong-arity`, as Ruby raises `ArgumentError` there. ([#2055](https://github.com/rigortype/rigor/pull/2055))
