- **[inference]** A variable written inside a call's receiver or arguments, an array or hash literal, an interpolation or a `rescue` modifier (`out << (n += 1)`, `puts(g = e)` inside a block) now reaches the code after the statement, so a later comparison no longer folds on the value it held before the write, and a local written in the right operand of an `&&` condition is no longer read as possibly `nil` in the branch that condition guards. [#1250](https://github.com/rigortype/rigor/pull/1250)
  - A mutator on a parenthesised write (`(buf ||= []) << x`) now widens the variable it writes, and one on an element an index `||=` stored (`groups[:a] ||= []; groups[:a] << x`) widens that element, so a later size check on it no longer folds.
  - `return` inside a lambda no longer adds to the enclosing method's inferred return type.
