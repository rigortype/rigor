- **[effects]** A controller action whose body spells a `respond_to` dispatcher now edges each `format.<fmt>` arm to that arm's own conventional template — `format.js` reaches `<action>.js`, a `format.js` arm whose block does not answer (`format.js { @users = [] }`) still reaches it, and an arm whose block answers outright (`format.js { render :other }`) names only the render — while `format.any` / `format.all`, which serve every request, name no template at all, and the single `<action>.html` implicit-render edge no longer stands in for an action whose top-level dispatcher covers it. ([#1071](https://github.com/rigortype/rigor/issues/1071), [#1160](https://github.com/rigortype/rigor/pull/1160))
