- **[engine]** `extend X` and `class << self; include X; end` written inside a block (`[1].each { extend X }`) are now recorded, so a class-method read through them no longer reports a false `undefined method`; a module whose `included do`, `class_methods do` or `self.included` hook extends its includer now leaves the includer's singleton chain unsettled, and reads through such a hook edge still report the false positive until the concern model lands.
