- **[sig]** The bundled ActiveSupport overlay and the `rigor-activesupport-core-ext` plugin now declare `Object#presence_in`, `#with`, `#with_options` and `#html_safe?`, `String#downcase_first`, `#acts_like_string?`, `#is_utf8?` and `#in_time_zone`, and `Symbol#starts_with?` / `#ends_with?`, so calls such as `1.html_safe?` and `params[:kind].presence_in(%w[a b])` no longer report a false `call.undefined-method`. The plugin no longer marks `Hash#deep_dup` as `%a{pure}`, because it runs each key's and value's own `dup`. If your project's `sig/` declared any of these methods itself to silence the old false positive, delete that declaration: the duplicate stops Rigor from building the class. ([#1334](https://github.com/rigortype/rigor/pull/1334))
