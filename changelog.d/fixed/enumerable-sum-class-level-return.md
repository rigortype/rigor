- **[inference]** `Enumerable#sum` now reads its result at class level, promoting each value by the seed the way Ruby's `+` does, so `[1, 2].each.sum(0.0)` is `Float` rather than `0.0 | 1 | 2` and `s == 3.0` no longer reports an always-falsey condition, while `Array#fetch` and other methods that return their argument keep its literal type.
