- **[plugins]** `rigor-ffi` now reads `./Gemfile.lock` and `ext/**/extconf.rb` through its `IoBoundary` when it detects its `:ffx` / `:ffi` target. Before, if one of those files changed with no source edit, `rigor check --incremental` and a cached `rigor check` reused the previous diagnostics in both directions: they missed the `plugin.ffi.ffx.unsupported-*` diagnostics when the project moved to ffx, and kept reporting them after it moved back. ([#1652](https://github.com/rigortype/rigor/issues/1652), [#1802](https://github.com/rigortype/rigor/pull/1802))
