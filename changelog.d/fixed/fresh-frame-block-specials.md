- **[engine]** A block handed to `Thread.new`, `Thread.start`, `Thread.fork`, `Fiber.new` or `Ractor.new` runs with a special-variable slot of its own, so it no longer reads the enclosing method's `$~` / `$1` narrowing, and a regex match inside it (`Thread.new { s =~ re }.join`, a stored `Fiber.new { … }` resumed later) no longer drops that narrowing; a `define_method` or `define_singleton_method` body, which reads the definer's globals only when the method is called, now reads a global narrowed where it is written as untyped. ([#1392](https://github.com/rigortype/rigor/pull/1392))
