- **[inference]** A multi-assign that stores into a hash or array slot (`h[:a], z = 1, 2`, including nested and splatted targets) now widens the collection exactly as `h[:a] = 1` does, in the same method and in sibling methods reading an instance variable, so a later `h[:a] == 0` no longer reports an always-truthy condition and a slot stored under a new key no longer reads as `nil`.
