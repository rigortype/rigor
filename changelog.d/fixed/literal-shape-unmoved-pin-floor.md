- **[inference]** A block fold (`map`, `find`, `select`, …) now treats a captured array or hash literal the block rebinds the way it already treats a captured number: when its analysis comes back on the very literal it started from, the value reads as untyped instead of that first-iteration literal, so a rebind the analyzer did not follow can no longer leave `r.last.size == 1` folding always-true.
