- **[inference]** A `begin` whose rescue arm retries now widens the locals and instance variables the primary body rebinds before raising, and takes the arm's rebinds from the scope at the `retry` itself, so the retry-counter idiom `tries += 1; raise "boom" if tries < 3` inside `begin … rescue; retry; end` and a backoff such as `wait = wait ? wait * 2 : 0.5; retry if wait < 5` no longer report `flow.always-truthy-condition`; a `nil`, `true` or `false` rebound across that retry edge stays a constant instead of widening to `NilClass` / `TrueClass` / `FalseClass`, so a declared `bool` or `String?` return keeps accepting it.
