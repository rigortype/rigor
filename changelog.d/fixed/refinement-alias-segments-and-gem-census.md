- **[engine]** A `refine` whose target is spelled through a constant alias in any segment (`Enc = ::Encoding; refine(Enc::Converter)`), or through a constant an opted-in gem (`dependencies.source_inference:`) assigns (`module Shared; Target = String; end` beside `refine(Shared::Target)`), no longer reports `call.undefined-method` on the refined call under its `using`; the gem source walker now reads a gem's `refine` calls through the same census as a project file, so a gem module's rows carry the same wildcard rows; and a warm run or an `--incremental` run re-checks after a bump of an opted-in gem even with no `Gemfile.lock`.
