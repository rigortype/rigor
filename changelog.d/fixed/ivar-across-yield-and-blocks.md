- **[engine]** An instance variable no longer keeps its pre-call value past a `yield`, a `super` or a call of a local proc (`blk.call`, `blk.()`) — as a statement, in a condition, in another call's receiver or arguments, or inside a block — nor past a block on another receiver whose body calls a method on `self`, so a condition on it afterwards no longer reports `flow.always-truthy-condition` on correct code; in an instance method of a class, a block run on a class object (`Other.class_eval { … }`, `self.class.instance_eval { … }`) no longer changes the instance's own instance variables. ([#2077](https://github.com/rigortype/rigor/pull/2077))
