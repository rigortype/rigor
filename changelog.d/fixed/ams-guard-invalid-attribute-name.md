- **[plugins/rigor-active-model-serializers]** A serializer class declared in several files that each name its superclass is read as one class, so a sibling file declaring the same class could hide the valid file's attributes from `object` typing, depending on file order, even when the sibling had no invalid attribute name; a class whose files name different superclasses is now left undecided ([#1864](https://github.com/rigortype/rigor/pull/1864)).
