- **[inference]** A block nested inside another multi-statement block whose result reads a local that block assigns no longer types its value from the pre-block state of a local or parameter it reassigns or mutates in place: after `k = m.synchronize do w = v; m.synchronize { i += w; i } end`, `k` types `Dynamic[top]` instead of `0`, so `k == 0` is no longer reported as always true, and `{ x: [], y: [] }.map { |_k, a| a << w; a }` in the same position types `Array[Array[Dynamic[top]]]` instead of `Array[[]]`. ([#1244](https://github.com/rigortype/rigor/pull/1244))
