- **[engine]** A call whose type comes from a plugin — `Rails.logger` under `rigor-railties`, say — no longer reports `undefined method` when your own `sig/` declares part of that receiver but not the method the plugin covers, so adding signatures to a project can no longer turn working, plugin-covered call sites into errors. ([#653](https://github.com/rigortype/rigor/issues/653), [#702](https://github.com/rigortype/rigor/pull/702))
