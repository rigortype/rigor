- **[inference]** A predicate on the left of `&&` / `||` now narrows the right operand when the expression is used as a value — an argument, an array element, a receiver, or the type `rigor type-of` reports — exactly as it does for the same expression written as a statement, so `x.finite? && x` reads `false | finite-float` everywhere.
