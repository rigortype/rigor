- **[engine]** `Array.new(n)`, `Array.new(n, value)` and `Array.new(n) { … }` with a non-literal size now carry an element type, so a value appended inside a later block or loop no longer replaces it: `acc = Array.new(n, "x"); [1].each { acc.push(1) }; acc.first.upcase` no longer reports `undefined method 'upcase' for 1` on correct code ([#615](https://github.com/rigortype/rigor/issues/615), [#650](https://github.com/rigortype/rigor/pull/650))
