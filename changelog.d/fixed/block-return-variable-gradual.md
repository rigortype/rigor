- **[inference]** A generic whose block returns a type variable that one of its parameters also names — `Enumerable#sum(init) { … }`, `Enumerable#inject(seed) { … }` on an Enumerator, `Enumerator.produce(initial) { … }` — no longer takes the block's type as its exact result, so `s = [1, 2].each.sum(0.0) { |x| x }; s == 3.0` stops folding always-falsey and a Float-seeded inject no longer rejects `nan?`. ([#1273](https://github.com/rigortype/rigor/pull/1273))
