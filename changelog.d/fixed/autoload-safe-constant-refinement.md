- **[engine]** Analysing a reference to a constant no longer loads and runs that library inside Rigor itself: a path such as `Prism::Translation::RubyParser` used to be resolved in the analyzer's own process, executing the target file — which for that example calls `exit` when an optional gem is missing, killing `rigor check` outright with no diagnostics and no summary. Constant refinement now answers only from a fixed list of core Ruby constants, so no code reachable from the source being checked is ever executed. ([#680](https://github.com/rigortype/rigor/issues/680))
