- **[inference]** A `begin` whose rescue arm retries now carries across the retry the locals and instance variables the primary body rebinds before raising, not only those the arm rebinds, and takes the arm's rebinds from the scope at the `retry` as well as the arm's exit, so the retry-counter idiom `tries += 1; raise "boom" if tries < 3` inside `begin … rescue; retry; end` and a backoff such as `wait = wait ? wait * 2 : 0.5; retry if wait < 5` no longer report `flow.always-truthy-condition`; a rebind that settles after one more pass keeps its literals (`:ok | :retrying`, `false | true`) instead of widening to `Symbol` or `FalseClass | TrueClass`, and an arm that can only retry or raise no longer joins the code after the `begin`.
