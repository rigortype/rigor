- **[engine]** A call passing keywords that an overload declares and accepts now selects that overload rather than one that would read the keyword hash as a positional argument: with `(a: Integer) -> Integer | (Object) -> String`, `ob(a: 1)` is `Integer` instead of `String`, so `ob(a: 1).even?` no longer reports `call.undefined-method`. A positional overload declared before the keyword one, or a keyword overload that takes the hash only gradually, joins the returns instead. ([#1800](https://github.com/rigortype/rigor/issues/1800), [#1808](https://github.com/rigortype/rigor/pull/1808))
