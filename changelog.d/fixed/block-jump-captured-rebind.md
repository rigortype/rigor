- **[inference]** A block that reassigns an outer local on a path leaving through `next` or `break` now carries that value past the call: `n = String.new; [1, 2, 3].each { |e| if e.odd?; n = e; next; end }; n.even?` no longer reports an undefined method for `String`, `found = nil; [1, 2, 3].each { |x| if x > 1; found = x; break; end }` no longer folds `if found` to always-falsey, and a `next` or `break` inside `begin … ensure` leaves with the value the `ensure` clause set. A loop `break(flag = true)` also keeps the write in its argument. ([#1215](https://github.com/rigortype/rigor/pull/1215))
