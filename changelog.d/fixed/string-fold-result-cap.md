- **[engine]** Every String-producing constant fold is now capped at 4096 bytes: a large format or pad width (`"%02000000000d" % 1`) or `gsub` replacement no longer builds a huge string and stalls the analyzer, `(2**13000).to_s(2)`, `tr` and `dump` no longer fold to a huge constant, and a union receiver with one oversized member no longer folds to the others alone.
