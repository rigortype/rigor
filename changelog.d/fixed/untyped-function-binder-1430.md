- **[inference]** A method your `sig/` declares with the untyped parameter list `(?)`, such as `def run: (?) -> Integer`, no longer fails its whole file with `internal analyzer error: NoMethodError: undefined method 'required_positionals'`. Its parameters read as `Dynamic[top]` inside the body and its declared return type still applies. The same crash is fixed for a `rigor:v1:assert` or `rigor:v1:predicate-if-*` annotation on such a method. ([#1434](https://github.com/rigortype/rigor/pull/1434))
