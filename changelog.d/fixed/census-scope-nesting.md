- **[engine]** An instance variable, class variable or constant assigned inside a compact namespace declaration — `@post = Post.new` in an `initialize`, or `DEFAULT = Post`, written in `class Admin::Census` — is now recorded as the class Ruby resolves it to rather than as a same-named class under the enclosing namespace, so every later read of it gets the right type instead of a false `undefined method`; the nested spelling of the same class keeps reaching the nearer class exactly as before. Two paths still read the old answer: a value that arrives through another method's inferred return type, and a constant assigned through a path (`Foo::BAR = Post`), which is still resolved as if written at the top level. ([#681](https://github.com/rigortype/rigor/issues/681))
