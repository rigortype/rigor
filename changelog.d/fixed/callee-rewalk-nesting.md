- **[inference]** A method's inferred return type now resolves its constants the way the class that declares the method spells its own namespace, so a value built inside a compact `class Admin::Controller` (or inside a superclass written in the other spelling) keeps the class Ruby gives it instead of picking up a same-named one under the enclosing module; the new resolution does not reach `--incremental`, where a method in a file the recheck did not re-read still resolves as it did before, so `--verify-incremental` can report a difference on a project that uses compact declarations ([#707](https://github.com/rigortype/rigor/issues/707)).
