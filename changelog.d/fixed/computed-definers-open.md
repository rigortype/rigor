- **[check]** `call.undefined-method` no longer fires on methods a class macro, `send(:define_method, m)`, `Other.define_method(m)`, a computed `define_singleton_method` or `attr_accessor(*NAMES)` defines. ([#2972](https://github.com/rigortype/rigor/pull/2972))
  - `def self.my_attr(*n) = n.each { |x| define_method(x) { } }` followed by `my_attr :foo` in a class with a `sig/` declaration reported `undefined method 'foo'`. A class whose body calls such a macro now reads as open on its instance side, as does its subclass. The macro may be the class's own, a superclass's or an extended module's, in any file.
  - `Other.define_method(m)` opens `Other` and leaves the enclosing class closed. A computed `define_singleton_method` opens the class object only. `attr_accessor(*NAMES)` and `send(:define_method, m)` open the side a literal name there would define on.
