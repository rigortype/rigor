- **[plugins]** `RIGOR_PLUGIN_ISOLATION=ruby_box` (and the legacy `RIGOR_BOX`) no longer crashes Rigor on a Ruby that has not fixed [Ruby Bug #22260](https://bugs.ruby-lang.org/issues/22260), which includes every release up to 4.0.7. The launcher now checks the running Ruby first; if the check fails it prints a warning and uses the configured isolation strategy (`process` by default). On a Ruby with the fix, which is currently CRuby master, `ruby_box` works and reports the same diagnostics as `process`. ([#1345](https://github.com/rigortype/rigor/pull/1345))
