- **[inference]** A constant assigned a Symbol, Integer, Float, or boolean literal in one file now types at its readers in every other file, so `DEFAULT_LIMIT = 50` in a config file is `50` everywhere it is used instead of untyped; a constant that two files assign, that one file assigns twice, or whose value is a String, Array, Hash, `nil`, or any computed expression stays gradual, and `flow.always-truthy-condition` no longer fires on a condition that reads such a constant directly or through a project predicate method. ([#644](https://github.com/rigortype/rigor/issues/644), [#669](https://github.com/rigortype/rigor/pull/669))
