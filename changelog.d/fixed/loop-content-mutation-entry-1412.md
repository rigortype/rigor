- **[inference]** Rigor no longer types a repeating block or loop body from the first iteration's contents of a local the body appends or stores to, so `depth = []; lines.each { |tl| puts depth.last.length if depth.last; depth << tl }` no longer reports `undefined method 'length' for nil`; the same holds for `while` / `until` / `for` bodies, and for a local an iterator's block rebinds when the receiver is untyped (`names = nil; io.each_line { |l| … names = {} … names[l] = true }`). A read that only the first iteration makes of such a local is no longer checked. [#1441](https://github.com/rigortype/rigor/pull/1441)
