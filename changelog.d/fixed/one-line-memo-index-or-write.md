- **[inference]** A memoizing index `||=` in a block whose result Rigor types per element or through the method's block signature — `cache = {}; [1, 2].find { |e| (cache[:first] ||= e) == 2 }` — no longer reads a later run's slot as empty, so `find` no longer folds to `2` and `found == 2` no longer reports a false `flow.always-truthy-condition`; this holds whatever the receiver (a captured hash or array, an instance or class variable, a constant, an attribute reader, a nested memo), while a memo whose key differs at each element keeps its precise type. `find` / `find_index` over a literal array also drop `nil` when a later element always matches, whatever the earlier ones answer.
