- **[engine]** `extend X` and `class << self; include X; end` written inside a block that provably runs (`[1].each { extend X }`, `tap`, `then`, `3.times`) in a class body are now recorded, so a class-method read through them no longer reports a false `undefined method`; blocks that may never run or run on another object (`Registry.each`, `@lock.synchronize`, `on_load` hooks) are still not read as the class's own, and a concern's `included do extend X end` or a `self.included(base)` hook that extends its includer is still not modelled. ([#1592](https://github.com/rigortype/rigor/issues/1592), [#1593](https://github.com/rigortype/rigor/pull/1593))
