- **[plugin API]** A `dynamic_return receivers:` entry now names the receiver kind: `"Widget"` matches an instance receiver, `"singleton(Widget)"` matches the class object, and a rule that wants both lists both — so an instance rule no longer answers (and, since the plugin answer suppresses `call.undefined-method`, no longer silences) a class-level call it never modelled ([#701](https://github.com/rigortype/rigor/issues/701), [#901](https://github.com/rigortype/rigor/pull/901)).
