- **[rigor unused]** `rigor unused` no longer reports a constant as unused when the plugin that names it reads its schedule file from outside the project through `plugins_io.allowed_paths` ([#2586](https://github.com/rigortype/rigor/issues/2586), [#3145](https://github.com/rigortype/rigor/pull/3145)).
  - `Reachability::PluginRoots` built its plugins' `Services` without the run's `TrustPolicy`, so a read outside the working directory was refused even when `plugins_io.allowed_paths` allowed it; it now builds the same policy `rigor check` derives, through the shared `TrustPolicy.for_configuration`.
  - A `~`-prefixed configured schedule path is now expanded before `RootedGlob.split_file` watches it, so the watch matches the `File.expand_path` read the schedule scans perform.
