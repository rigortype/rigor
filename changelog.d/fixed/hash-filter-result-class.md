- **[inference]** `Hash#select`, `#filter` and `#reject` with a block that always drops every entry now type as an empty Hash (`{}`) rather than an empty Array, so writing into the result (`r = h.reject { true }; r[:x] = 1`) no longer reports `call.argument-type-mismatch`. A block that keeps every entry of a `Set` or `Range`, or of a Hash under `take_while` / `drop_while`, now types as the Array those methods return instead of the receiver's class.
