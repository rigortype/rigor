- **[plugins]** Under the experimental Ractor pool backend (`RIGOR_POOL_BACKEND=ractor`), a run with a plugin that declares rules, producers or a manifest callable (rigor-ffi, rigor-dry-schema and most bundled plugins) no longer loses every worker to `Ractor::IsolationError`; a plugin block that cannot be shared across Ractors now declines the pool with a `pool-degraded` row naming the plugin. ([#2088](https://github.com/rigortype/rigor/pull/2088))
