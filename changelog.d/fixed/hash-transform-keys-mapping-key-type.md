- **[inference]** `Hash#transform_keys(mapping)` now includes the mapping's values in the new key type, with or without a block, so `{ a: 1, b: 2 }.transform_keys({ a: :z }) { |k| k }` types `Hash[:a | :b | :z, 1 | 2]` rather than `Hash[:a | :b, 1 | 2]`, and `r.keys.first == :z` is no longer reported as always falsey. ([#1247](https://github.com/rigortype/rigor/pull/1247))
