- **[inference]** How an instance variable's `@x += v` (or any other operator write) types the variable in the class's other methods no longer depends on the order the methods are written in. The write is now applied to every value the class's other writes store, so `@x = 1`, `@x &&= 1.5` and `@x += 1` in three methods no longer report `flow.always-truthy-condition` on `x == 2.5` when the `+=` is written above the `&&=`. ([#1343](https://github.com/rigortype/rigor/pull/1343))
