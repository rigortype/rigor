- **[config]** A `~` in a `.rigor.yml` path key, or in a path argument or template-unit path, is now a directory name rather than a user's home: a directory named `~drafts` no longer makes `rigor check` raise `ArgumentError: user drafts doesn't exist`, and `paths:` entries are resolved with `File.absolute_path` semantics. ([#1510](https://github.com/rigortype/rigor/issues/1510), [#1639](https://github.com/rigortype/rigor/pull/1639))
