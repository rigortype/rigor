- **[inference]** A block that rebinds a local from a collection it also mutates in place — `last = a.last; a << x`, `top = stack.pop; stack.push(x)`, `seen = h[k]; h[k] += 1` — no longer types that local as the block's first iteration, so `a = [0]; [1, 2].each { |x| last = a.last; a << x }` stops reporting `last == 1` as an always-falsey condition.
