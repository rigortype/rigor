- **[inference]** A block that stores a value computed from the collection it mutates — `h[k] = h[k] + 1`, `a << a.last + x`, `a[0] += 1`, or an `each_with_object` memo read back through its block parameter — now widens that collection past the block's first iteration, so `h = { a: 0 }; [:a, :a, :a].each { |k| h[k] = h[k] + 1 }` reads `Hash[Symbol, 0 | Integer]` and `h[:a] == 3` no longer reports an always-falsey condition. ([#1207](https://github.com/rigortype/rigor/pull/1207))
