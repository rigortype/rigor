- **[rigor check]** A method defined only under a condition, inside a block other than a `Class.new` / `Module.new` / `Struct.new` / `Data.define` body, in a rescuing `begin`, or in a class reopened under a modifier is now read as possibly absent, so the rules that ask which definition a call reaches (`call.wrong-arity` and the override and visibility lints) stay silent where that definition may not exist instead of checking against it. ([#1562](https://github.com/rigortype/rigor/issues/1562), [#1623](https://github.com/rigortype/rigor/pull/1623))
