- **[sig-gen]** `rigor sig-gen` and `rigor annotate` now include a `return` written inside a block in the method's proposed return type, so `def a(flag) = @m.synchronize { return nil if flag; 1 }` proposes `-> (1 | nil)` instead of `-> 1`. A `return` inside a lambda or a `define_method` body still belongs to that inner definition, and a block `return` of an untyped value now skips the method as `sig.skipped.untyped-return`. ([#1390](https://github.com/rigortype/rigor/pull/1390))
