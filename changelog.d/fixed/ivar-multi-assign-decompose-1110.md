- **[inference]** Destructuring into instance variables (`@first, *@rest = ints`, `@a, @b = 1`, nested and union right-hand sides) now follows the same rules as locals instead of recording `Dynamic[top]`, both in the method that assigns them and in the type other methods of the class read; a fixed slot filled from a non-tuple `Array[T]` reads as `T | nil` in those other methods, because a short array leaves it `nil`.
