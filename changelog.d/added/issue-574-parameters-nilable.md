- **[plugins]** `params[:key]` now types as a nilable `ActionController::Parameters` instead of `Dynamic`, so chained reads like `params[:user][:name]` carry a type — the single largest untyped receiver pair on both survey applications. It lands with an engine fix that stops `call.possible-nil-receiver` treating a class nothing knows the surface of as proof that a nil check is missing, so `q = params[:q]; q.strip` stays silent; measured on redmine and mastodon with byte-identical diagnostics and type precision up 0.68 and 0.38 points.
