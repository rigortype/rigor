- **[config]** A new `test_paths:` key declares where the project's tests live (several directories allowed; unset auto-detects `spec/` and `test/`), and `rigor sig-gen --params=observed` now observes those roots instead of only `spec/`, so a Minitest project's `test/` types parameters without `--observe`. `rigor init` writes the roots it finds, and a declared root that does not exist is a config warning.
