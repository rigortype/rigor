- **[sig-gen]** **BREAKING** — `rigor sig-gen` now writes a method declared inline by `# @rbs` / `#:` into `sig/` as that declaration (a parameter-only annotation keeps its parameters and takes the return from the body, and that inferred return follows the usual proposal rules), and `--write` replaces a `sig/` copy whose inline declaration has since changed; a project whose Steep reads the same annotations (`inline: true` beside `signature "sig"`) must set `sig_gen: { inline_declared: skip }` in `.rigor.yml`, or Steep reports each copied method as `DuplicatedMethodDefinition`. The new `rigor sig-gen --check` exits 1 when `--write` with the same options would change `sig/`, for use as a CI freshness gate. Combining two of `--print`, `--diff`, `--write` and `--check` is now a usage error (exit 64) instead of the last flag silently winning. ([#1422](https://github.com/rigortype/rigor/pull/1422))
