- **[engine]** A method that passes its own block on (`g(x, &)` or `g(x, &blk)`) now gives the callee's `yield` the caller's block type, including an RBS-declared callee (`def m(arr, &) = arr.map(&)` called with `{ "a" }` is `Array["a"]`), and the caller's block is treated as one that may run more than once. A block-return pass that types a `return` without the statements before it no longer adds that `return` to the enclosing method's return type where the full walk of the block records it, so such helpers no longer read `untyped`. ([#2301](https://github.com/rigortype/rigor/pull/2301))
