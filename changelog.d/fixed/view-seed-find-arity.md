- **[plugins]** rigor-actionpack no longer seeds a view's `@ivar` as a single model when the controller assigned it from a call that returns several records — `Model.find(a, b)`, `Model.find([1, 2])`, `Model.find(*ids)`, a `find` with a block, or `Model.create([…])` — so the template no longer contradicts the `Array[Model]` rigor-activerecord gives the controller; the ivar reads `Dynamic` instead.
