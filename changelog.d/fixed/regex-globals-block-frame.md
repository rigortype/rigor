- **[engine]** A regex match inside a block, or inside a lambda or `proc` made in the same method, now drops the enclosing method's `$~` / `$1` narrowing, because Ruby shares those globals between a method and its blocks and closures: after `items.each { |i| i =~ /(z)/ }` on a match edge `$1` reads `String?` instead of `String`, and a block with no match keeps the narrowing.
