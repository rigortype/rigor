- **[inference]** Reading a hash shape — a literal hash or an RBS record type — with a computed key (`o = { a: 1 }; o[name]`) now includes `nil` for the keys it does not declare, so `o[name] == 1` is no longer reported as an always-truthy condition; binding such a read and calling a method on it can now report `call.possible-nil-receiver`, as a `String#[]` read does. A key that can only be one of the declared literal keys reads their values exactly, and `h.default = …` / `h.default_proc = …` / `h.compare_by_identity` now widen a literal hash (keeping its keys and its non-emptiness) instead of leaving its reads pinned to the literal.
