- **[inference]** A String-literal method name with bytes no Symbol can hold (`alias_method "\xff", :x`, `private "\xff"`, `module_function "\xff"`, `method("\xff")`, `attr_accessor "\xff", :ok`) no longer aborts `rigor check` or `rigor sig-gen` with an `EncodingError` internal analyzer error. Such a name now reads as a computed one, so nothing is recorded for it and the rest of the file is analysed. ([#1821](https://github.com/rigortype/rigor/issues/1821), [#1825](https://github.com/rigortype/rigor/pull/1825))
