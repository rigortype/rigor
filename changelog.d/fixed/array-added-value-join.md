- **[engine]** A collection mutated in place now covers the value the mutation added, so correct code like `u = [1, 2]; u.push(6)` no longer reports `u.last == 6` as an always-false condition, and an array built by index-writing an empty literal (`stack = []; stack[i] = n`) reads its element type instead of `untyped`.
