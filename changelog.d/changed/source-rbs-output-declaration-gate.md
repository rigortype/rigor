- **[rigor check]** With `rigor-rbs-inline` loaded (the default whenever the `rbs-inline` gem resolves), an `--incremental` edit that leaves a file's declarations and synthesized RBS unchanged, such as a comment or a same-line body edit in a file without annotations, now re-checks only that file (on Mastodon, 311 files in 13 s became 1 file in 2 s), and `enabled: false` on the plugin entry is honoured there too; in an annotated file, an edit that changes what rbs-inline writes, such as editing an annotation or a comment or adding, removing or renaming a `def`, now re-analyses the whole project. ([#1536](https://github.com/rigortype/rigor/issues/1536), [#1545](https://github.com/rigortype/rigor/pull/1545))
