- **[inference]** `Ext = Module.new(&BODY)` (and `Class.new`, `Struct.new(:a, &BODY)`, `Data.define(:a, &BODY)`, `&:sym`, `&method(:x)`) no longer aborts the file with an internal analyzer error. The constant is declared and its surface is treated as unknown, as for a `module_eval` with a non-literal body. ([#1816](https://github.com/rigortype/rigor/issues/1816), [#1824](https://github.com/rigortype/rigor/pull/1824))
