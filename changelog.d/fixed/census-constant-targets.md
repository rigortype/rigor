- **[inference]** A constant rebound in another file through a splat or nested multiple-assignment target (`x, *LIMIT = 2, 3`, `(LIMIT, y), z = …`), a `for` index, a `rescue => LIMIT` reference, or a write in a class or module header (`class Sub < (LIMIT = Base)`) now stops that constant's literal from publishing project-wide, so `LIMIT.first` no longer reports `call.undefined-method` for the other file's `LIMIT = 1`. ([#3407](https://github.com/rigortype/rigor/issues/3407))
