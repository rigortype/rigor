- **[plugins]** A mailer, job, Sidekiq worker, channel, attachment owner or controller declared as `class ::Foo`, or reopened in a second file, keeps its whole surface — `rigor-actionmailer`, `rigor-activejob`, `rigor-sidekiq`, `rigor-actioncable`, `rigor-activestorage` and `rigor-actionpack` now index every declaration under its plain name and merge the reopens into one entry, so actions, `#perform` arities, stream names, attachments and filter targets no longer depend on which file the loader happened to read last. ([#621](https://github.com/rigortype/rigor/issues/621), [#646](https://github.com/rigortype/rigor/pull/646))
