- **[engine]** A `singleton_class.alias_method`, `define_method` or `remove_method` whose names are literals, written directly in a class body or at the top level, now hides only the singleton methods it names, so `call.wrong-arity` again reports `D.own(1, 2)` after `singleton_class.alias_method :o2, :own`; the same call in a method body or hook still hides every singleton method of that class. A warm `--incremental` run now re-checks callers when a file that rewrites a class's singleton methods from outside its body changes which names it rewrites. ([#1906](https://github.com/rigortype/rigor/issues/1906), [#1933](https://github.com/rigortype/rigor/pull/1933))
