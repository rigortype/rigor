- **[inference]** A `map` / `select` / `find` block over an array literal no longer loses a captured local's class when the block both mutates it and reassigns it as a statement, so `s = +"ab"; [1, 2].map { |e| s << "c"; s = s.strip; s }` types `[String, String]` again rather than `[Dynamic[top], Dynamic[top]]`, and a nested block's own parameter that shares a captured local's name (`[[]].each { |a| a = k }`) is no longer mistaken for a reassignment of the outer local. ([#1279](https://github.com/rigortype/rigor/pull/1279))
