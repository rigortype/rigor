- **[rigor check]** An `--incremental` edit that leaves a file's declarations and inline RBS unchanged, such as a comment or a same-line body edit, now re-checks only that file even when `rigor-rbs-inline` is loaded (on Mastodon, 311 files in 13 s became 1 file in 2 s), while an edit that changes what an inline annotation contributes re-checks the whole project instead of serving callers a stale type, and `enabled: false` on the plugin entry is now honoured there too.
