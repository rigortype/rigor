- **[inference]** A block-form `inject` / `reduce` now reads a captured local, instance variable or collection as an earlier iteration may have left it, so a block that rebinds or mutates one (`r = a + n; n += 1; r`, `log << e`, `cache[:k] ||= e`) no longer folds to the first iteration's constant and raises a false `flow.always-truthy-condition`; a mutation through a block-local alias (`l2 = log; l2 << e`) now widens the captured collection in every per-element fold ([#1877](https://github.com/rigortype/rigor/pull/1877)).
