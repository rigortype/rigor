- **[inference]** When a block's earlier statements store into a captured hash or array through `h[k] += v`, `h[k] ||= v` or `h[k] &&= v` (or a multi-assign `h[k], x = …` inside a nested block), the block's last statement now reads the widened collection instead of the literal, so `v = m.synchronize { h[:a] += 1; h[:a] }` no longer reports `v == 0` as always truthy.
