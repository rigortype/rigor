- **[inference]** A block or lambda parameter that shadows an outer local no longer reads as that outer local inside a closure Rigor does not evaluate in place — a block passed as an argument, in a receiver chain, in a literal or on `super`, a nested block's implicit `it`, or a lambda's parameter defaults — so `o = { x: 1 }; show([1, 2].map { |o| o + 1 })` no longer reports an undefined `+` for the Hash.
