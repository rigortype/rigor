- **[perf]** `rigor check` no longer holds every analysed file's discovery index for the length of the run: the class-graph resolver memo kept one bucket per file, keyed by the index itself, and reused one across files 58 times in 80,106 lookups. It now keeps a single bucket, replaced when the file's index changes, so a `lib`+`plugins` run over this repository ends holding 28.7 MB less object memory and allocates slightly fewer objects, with byte-identical diagnostics. A sequential run's reported memory peak falls about 6%; a `--workers=N` run's does not move, because that figure is the coordinator's own RSS and the workers hold their own copies.
