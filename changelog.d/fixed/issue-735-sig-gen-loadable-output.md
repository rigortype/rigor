- **[sig-gen]** `rigor sig-gen --write` no longer emits a declaration whose superclass no loaded RBS declares (it is skipped, and the unresolved superclass is named on stderr) and writes a generic superclass with its type arguments, so the generated `sig/` no longer collapses classes on the next run; a class the project declares in its own `sig/` also stops drawing `call.undefined-method` for methods the project defines in another of its files. ([#735](https://github.com/rigortype/rigor/issues/735), [#737](https://github.com/rigortype/rigor/pull/737))
