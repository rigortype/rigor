- **[plugins]** Ordinary Rails code on a `Time` value no longer draws a false `undefined method` — `Time.current.to_fs(:db)`, `.in_time_zone`, `.past?`, `.future?`, `.today?`, `.formatted_offset`, `.at_beginning_of_hour`, `.middle_of_day` and the rest of the ActiveSupport `Time` instance surface (`days_ago`, `beginning_of_quarter`, `next_occurring`, `all_week`, `seconds_since_midnight`, …) now type, in both rigor-activesupport-core-ext and the auto-applied activesupport overlay, while a genuine typo on a `Time` receiver still reports; `time.at_beginning_of_week(:sunday)` also stops drawing an arity error. ([#658](https://github.com/rigortype/rigor/issues/658))
