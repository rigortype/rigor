- **[inference]** A class guard written as a nested constant path — `x.is_a?(Type::Union)`, `case x when Type::Union`, `Type::Union === x` — now resolves that path the way Ruby does, through the enclosing `module` nesting, so the guarded receiver keeps its real type instead of falling back to `untyped` and losing every method call made on it. ([#635](https://github.com/rigortype/rigor/issues/635))
