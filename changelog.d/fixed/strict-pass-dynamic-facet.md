- **[inference]** A call whose argument Rigor knows only partly, but knows to be an `Integer`, a `Float` or another built-in value (such as `Integer(v)` or `Float(v)` on an untyped `v`), now picks the RBS overload for that class instead of the receiver's own: `1 + Float(v)` types as `Float` rather than `Integer`, and with `def add: (Integer) -> Integer | (Money) -> Money` in `sig/`, `money.add(Integer(v)).even?` no longer reports `call.undefined-method`.
