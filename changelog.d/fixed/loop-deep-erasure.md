- **[engine]** A loop or block that mutates an element in place no longer leaves the collection's shape stale, which drew a false `flow.always-truthy-condition` on `a = [[1]]; a.each { |x| x << 2 }; a[0].size == 2` and on `a = [[1]]; for x in a; x << 2; end; a[0].size == 2`. ([#2285](https://github.com/rigortype/rigor/pull/2285))
  - The collection's variables now drop their shapes at every depth when the body calls a mutator on a block parameter or `for` index (a nested block's or nested `for`'s too, `it` and `_1` included), on an index chain rooted at one, or names a mutator as a symbol proc (`a.each(&:strip!)`). A body that only reads the element, or mutates an unrelated local, keeps the precise shape.
  - An alias of the element (`y = x`) and an element passed to a call are not followed.
- **[engine]** A loop nested in a ternary branch or `unless` modifier inside another loop (`id(c ? (while …) : 0)`, eight deep) is no longer evaluated again for each typing of the conditional, which took minutes. ([#2285](https://github.com/rigortype/rigor/pull/2285))
