- **[rigor-grape]** `desc 'x' do ... end` bodies now bind `self` to the declared `Grape::DSL::Desc::ConfigContext` — the closed `ROUTE_ATTRIBUTES` setter surface (`detail`, `success`, `failure`, `tags`, `entity`, `hidden`, `is_array`, `consumes`, `headers`, `summary`, `deprecated`, `named`, `nickname`, `produces`, `security`, `http_codes`, `body_name`, `default`, `description`, `params`) — so desc-block documentation calls type instead of reading `Dynamic[top]` (~4,600 opaque sites on gitlab's `lib/api`). An undeclared name inside a `desc` block reads `call.undefined-method`, matching Grape's runtime `NoMethodError`.
