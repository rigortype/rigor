- **[inference]** A `while` / `until` / `for` loop that reassigns a local on a path leaving through `next` now carries that value past the loop: `w = String.new; i = 0; while i < 3; i += 1; if i.odd?; w = i; next; end; end; w.even?` no longer reports an undefined method for `String`, and a `rescue … ; failed = true; next` flag no longer folds `if failed` to always-falsey. A `while` / `until` `break` that only a later iteration reaches (`break(flag = true) if i == 2`) now joins too, instead of leaving `flag` as `false`. ([#1248](https://github.com/rigortype/rigor/pull/1248))
