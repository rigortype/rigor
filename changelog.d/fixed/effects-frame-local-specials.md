- **[effects]** A write to `$_` or `$~` and a read of `$@` no longer count as global effects, so a `%a{pure}` method that does one no longer reports `effect.envelope-exceeded`; a global written as a multiple-assignment, `for` or `rescue =>` target now counts as `global.write`.
