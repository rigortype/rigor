- **[inference]** A constant or class variable holding a hash or array literal that the file mutates no longer reads its literal contents as the only possible values, so `H = { a: 1 }; H.default = 0; H[:b] == 0`, `T[:b] = 2; T[:b] == 2` and `A << 2; A.last == 2` no longer fold always-falsey, and `T[:a] = "x"; T[:a].upcase` no longer reports an undefined method on `1`.
