- **[inference]** A collection passed to a method the class inherits that mutates it no longer keeps its literal contents after the call, so a later read no longer reports a false diagnostic on them. ([#2570](https://github.com/rigortype/rigor/pull/2570))
  - `acc = INIT.dup; poke(acc); acc[0].upcase`, with `poke` defined on the superclass and writing `acc[0]`, reported `call.undefined-method` for the literal `7`; the self-call now resolves along the class's ancestors, as Ruby dispatches it, and an inherited method is floored without being read.
  - A method that hands the collection to the method it overrides (`super`, `super(acc)`, or a rest parameter passed on with `super(*args)`, `super(**kw)` or `super(...)`) now floors it too, and so does a call no method answers in a class that defines `method_missing`.
