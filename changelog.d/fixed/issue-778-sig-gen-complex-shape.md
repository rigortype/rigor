- **[sig-gen]** `rigor sig-gen` now emits a signature for every method whose return it can infer, whatever its parameter shape (optional, rest, keyword, keyword-rest, `...` forwarding, `&block`), instead of silently dropping every method beyond required positionals; `--format=json` lists each method it declined with its `skip_reason`, and text mode prints a one-line stderr count per reason. ([#778](https://github.com/rigortype/rigor/issues/778), [#797](https://github.com/rigortype/rigor/pull/797))
