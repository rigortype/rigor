- **[effects]** An `include` or `prepend` written inside `class << self` or `singleton_class.class_eval` is no longer treated as an instance-side include, since Ruby mixes the module into the class's singleton class there, as `extend` does. A `super` in an instance method no longer resolves into that module's method, and `Foo.new` no longer picks up the module's `initialize`, so neither puts that module's effects on the caller.
