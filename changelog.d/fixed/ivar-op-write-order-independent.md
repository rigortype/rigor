- **[inference]** How an instance variable's `@x += v` (or any other operator write) types the variable in the class's other methods no longer depends on the order the methods are written in, and a method that sets the variable to `nil` no longer stops the write from being applied to its other values. So `@x = 1`, `@x &&= 1.5` and `@x += 1` in three methods no longer report `flow.always-truthy-condition` on `x == 2.5` when the `+=` is written above the `&&=`, and neither do `@x = 0.5`, `@x += 1` and `@x = nil` on `x > 1.0` under `x.is_a?(Float)`. ([#1343](https://github.com/rigortype/rigor/pull/1343))
