# Survivors

Firings that a correct change to `SourceArity`'s decision point MUST keep: each is a plain definition no
unsettled chain, hook or conditional touches, and each is a real arity error under Ruby. The job's floor counts only
these rows (`--require-rows-in`), so a change that silences a true positive of the ordinary kind cannot hide behind
the shapes it is meant to silence.

`named_mark_discharged.rb` is the one survivor with a conditional `include`: its module cannot answer the name, so
the candidate-set read discharges the mark (ADR-119 WD2's relevance) and the firing stays. A change that drops
relevance silences it and the differential reports an unadjudicated removal.
