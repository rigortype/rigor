- **[rbs]** A project that wires `rigor-activesupport-core-ext`'s signatures through `signature_paths:` instead of `plugins:` no longer loads Rigor's bundled ActiveSupport overlay on top of them: the duplicate declarations used to collapse `Time`, `Integer`, `String` and any project class whose signature named them, so every call into those classes read `Dynamic[top]` and the run went silent while still exiting 0.
