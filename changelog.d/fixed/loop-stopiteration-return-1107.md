- **[inference]** `loop { ... }` is no longer typed as never returning when its body can raise `StopIteration`: the enumerator-draining idiom `loop { out << e.next }` now returns `untyped` (the stopped enumerator's result) instead of `bot`, so `flag ? [].then { |a| loop { a << e.next } } : nil` no longer reports an always-falsey condition; a body that cannot raise keeps its `break` value exactly (`loop { break 5 }` is still `5`).
