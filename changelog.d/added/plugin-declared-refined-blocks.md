- **[plugins]** A `block_as_methods:` entry can declare `refinements:`, the modules a method runs the caller's block under through Ruby 4.1's `Proc#refined` (`instance_exec(&block.refined(M))`, as activerecord-refined's `where` / `select` / `joins` do). Refined calls in that block and its nested blocks then no longer report `call.undefined-method` or argument mismatches. A new `self_type: :lexical` keeps the caller's `self` for a method that only calls `block.refined(M)`. ([#1667](https://github.com/rigortype/rigor/issues/1667), [#1744](https://github.com/rigortype/rigor/pull/1744))
