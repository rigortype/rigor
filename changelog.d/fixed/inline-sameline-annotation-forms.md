- **[rbs-inline]** An `%a{…}` annotation written on the same line as its method type — `# @rbs %a{…} () -> String` or `#: %a{…} () -> String`, the spellings rbs's built-in inline parser and Steep accept — now applies both the annotation and the method type, instead of leaving the method untyped (and, for `#:`, reporting the valid line as unparseable); a same-line method type that really does not parse is reported.
