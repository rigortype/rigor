- **[engine]** A block passed with an argument that is `Dynamic` over one or two sealed types (`visit(n) { |v| v.even? }` with `n : Dynamic[Integer]`) no longer binds the first overload's block parameters when that argument cannot pick an overload. It binds them only when every overload the call may reach agrees, so `undefined method 'even?' for String` no longer fires on correct code. A keyword call with such an argument and a union keyword value also joins the return of every overload it may reach. ([#1781](https://github.com/rigortype/rigor/pull/1781))
