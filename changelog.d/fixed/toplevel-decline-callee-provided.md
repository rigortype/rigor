- **[engine]** `call.unresolved-toplevel` no longer reports a bare call inside a top-level block passed to a project method defined through `define_singleton_method` or `define_method`, or by a `def` inside a block or a method body, that may run the block under another `self`. ([#2263](https://github.com/rigortype/rigor/pull/2263))
  - It also declines inside every top-level block when a project `method_missing` may run the block under another `self`, and inside the block of a `define_method` / `define_singleton_method` call, which Ruby runs as a method body.
  - A block passed to a method that only `yield`s still reports.
