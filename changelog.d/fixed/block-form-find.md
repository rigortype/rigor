- **[plugins/rigor-activerecord]** The block form of `find` (`Post.find { |post| post.title == "x" }`, `Post.find(&:published?)`) no longer reports `plugin.activerecord.wrong-arity`, or `call.undefined-method` where the model has an RBS signature. It is `Enumerable#find` over the records and types as `Post | nil`. A relation's `find { … }`, which was typed as the model, now answers the same, so using its result without a nil check reports `call.possible-nil-receiver`.
