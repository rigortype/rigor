- **[engine]** Code in the arm a Ruby-version guard rules out no longer reports: when `rigor` can decide the condition from literals — `RUBY_VERSION >= "3.1"`, `Gem::Version.new(Psych::VERSION) >= Gem::Version.new("3.1.0.pre1")`, `RUBY_ENGINE == "jruby"` — the branch that cannot run on the Ruby you are checking with is treated as unreachable, so the older-API call inside it stops drawing arity and argument errors, and its assignments no longer widen the types seen after the `if`. A guard `rigor` cannot decide keeps both branches checked exactly as before, and the guard itself is never flagged as a redundant condition. ([#627](https://github.com/rigortype/rigor/issues/627), [#647](https://github.com/rigortype/rigor/pull/647))
