- **[plugins]** `rigor-minitest` no longer replaces a local's type after `assert_equal(literal, x)` or `_(x).must_equal(literal)`, since `==` is not identity: a class with its own `==` (a `ModInt` comparing `to_i` passes `assert_equal 9, m`) and cross-class numerics (`1 == 1.0`) no longer leave `x` as the literal and report `call.undefined-method` on correct code. `x` narrows to a `nil`, boolean or Symbol literal as before, and to an Integer, Float or String literal only when its type is already of that class (`x = rand(10); assert_equal 9, x` still gives `9`). ([#1678](https://github.com/rigortype/rigor/issues/1678), [#1806](https://github.com/rigortype/rigor/pull/1806))
