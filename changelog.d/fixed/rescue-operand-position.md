- **[engine]** A `begin … rescue` in an operand position (a call argument, a hash value, an array element, an interpolation or a method-chain receiver, outside a `return`, `next`, `break` or `yield` value) and a rescue modifier's fallback now see the body's writes, so `take(begin; conn = make; work; rescue; conn.size; end)` and `(conn = make; work) rescue conn.size` no longer report `undefined method 'size' for nil` on correct code. ([#2111](https://github.com/rigortype/rigor/pull/2111))
