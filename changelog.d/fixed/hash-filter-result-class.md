- **[inference]** `Hash#select`, `#filter` and `#reject` with a block that drops every entry now type as an empty Hash rather than an empty Array, so writing into the result (`r = h.reject { true }; r[:x] = 1`) no longer reports `call.argument-type-mismatch`. ([#1263](https://github.com/rigortype/rigor/issues/1263), [#1265](https://github.com/rigortype/rigor/pull/1265))
  - A block that keeps every element of a `Set` or `Range`, or every entry of a Hash under `take_while` / `drop_while`, now types as the Array Ruby returns instead of the receiver's class. That removes a false `call.undefined-method` on code such as `("a".."c").select { true } << "d"`.
