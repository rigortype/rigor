- **[inference]** A block-form `inject` / `reduce` now reads a captured local, instance variable or collection as an earlier iteration may have left it, so a block that rebinds or mutates one (`r = a + n; n += 1; r`, `log << e`, `cache[:k] ||= e`) no longer folds to the first iteration's constant and raises a false `flow.always-truthy-condition`. A mutation through a block-local alias (`l2 = log; l2 << e`) now widens the captured collection wherever Rigor reads a repeating block or loop body's in-place mutations: the per-element folds such as `map`, the generic block-return pass, the entry of a repeating block, and `while` / `until` / `for` bodies ([#1877](https://github.com/rigortype/rigor/pull/1877)).
