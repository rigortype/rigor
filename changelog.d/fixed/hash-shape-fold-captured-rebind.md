- **[inference]** `transform_values` / `transform_keys` over a hash whose keys are statically known no longer read a captured local the block reassigns at its first-iteration value for every key: after `total = 0; r = { x: 1, y: 2 }.transform_values { total += 1 }`, `r` types `{ x: Integer, y: Integer }` instead of `{ x: 1, y: 1 }`, so `r[:y] == 1` is no longer reported as always true.
