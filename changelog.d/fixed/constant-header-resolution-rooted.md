- **[engine]** A class or module opened with a leading `::` is now known by the name Ruby gives it wherever it is written — `class ::Admin::Widget` inside `module Outer` is `Admin::Widget`, not `Outer::Admin::Widget` — so its constants resolve correctly and, for a single-segment `class ::Foo` inside `module MyApp`, the class stops being invisible: calls on `Foo` used to resolve to nothing, type opaque, and report no diagnostic at all. ([#708](https://github.com/rigortype/rigor/issues/708), [#638](https://github.com/rigortype/rigor/issues/638), [#721](https://github.com/rigortype/rigor/pull/721))
