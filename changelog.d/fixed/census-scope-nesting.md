- **[engine]** An instance variable, class variable or constant assigned inside a compact namespace declaration — `@post = Post.new` in an `initialize`, or `DEFAULT = Post`, written in `class Admin::Census` — is now recorded as the class Ruby resolves it to rather than as a same-named class under the enclosing namespace, so every later read of it gets the right type instead of a false `undefined method`; the nested spelling of the same class keeps reaching the nearer class exactly as before. A value that arrives through another method's inferred return type is the one path that still reads the old answer. ([#681](https://github.com/rigortype/rigor/issues/681))
