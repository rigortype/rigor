- **[inference]** A string literal no longer keeps its value after `delete_prefix!`, `delete_suffix!`, `encode!`, `scrub!`, `unicode_normalize!`, `setbyte`, `bytesplice` or `append_as_bytes`, so `s = +"ab"; s.delete_prefix!("a")` no longer makes `s == "ab"` report an always-truthy condition; an instance variable or constant seeded with a string literal is likewise widened when another method mutates it in place, and a `non-empty-string` refinement is now dropped after `tr!`, `tr_s!` and the other calls that can empty the string. ([#1270](https://github.com/rigortype/rigor/pull/1270))
  - **[effects]** `force_encoding` and the calls above now count as receiver mutations on a `String`: `rigor effects` labels a method that makes them on a string it does not own with `mutate.*`, and with `effects.check` enabled a `%a{pure}` method that does so reports `effect.envelope-exceeded` (a committed effect snapshot may need regenerating).
