- **[engine]** A constant path is resolved the way Ruby resolves it, one segment at a time — the first segment through the lexical nesting and the enclosing class's ancestors, each later segment inside the constant the previous one produced — so `A::B` written where `A` inherits `B` from a superclass or an included module names that class instead of an unrelated top-level `A::B`, and the `undefined method` reports that followed from the wrong class stop ([#905](https://github.com/rigortype/rigor/pull/905))
