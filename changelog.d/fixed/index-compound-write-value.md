- **[inference]** `h[k] += v`, `h[k] ||= v` and `h[k] &&= v` used as a value — a block's result or a method argument — now type as the value they store instead of their right-hand side, so `r = words.map { |w| counts[w] += 1 }` no longer reads `[1, 1, 1]` and `r.last == 1` no longer draws a false `flow.always-truthy-condition`; a memoizing `cache[key] ||= build` whose slot is untracked still reads as `build`.
