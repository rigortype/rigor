- **[testing]** `Rigor::Testing.dump_type` / `assert_type` (and the `Rigor.` delegates) now declare a generic `[A] (…, A value) -> A` return instead of `-> untyped`, so a probed value keeps its type when the helper's result is read again rather than widening to `Dynamic[top]`. The binding applies to `Rigor.` / `Rigor::Testing.` receivers and to RBS-known including classes; a bare `dump_type(x)` inside a discovered-only class still answers `Dynamic[top]`, as before.
