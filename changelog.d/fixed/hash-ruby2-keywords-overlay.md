- **[engine]** `Hash.ruby2_keywords_hash?` and `Hash.ruby2_keywords_hash` resolve through the core overlay, so `Hash.ruby2_keywords_hash?({})` no longer reports `call.undefined-method` on correct code. No rbs release declares either method; Ruby 4.1 deprecates both and removes them in 4.5, and `call.deprecated-ruby2-keywords` still reports them under an explicit `target_ruby: "4.1"`. ([#1778](https://github.com/rigortype/rigor/issues/1778), [#1790](https://github.com/rigortype/rigor/pull/1790))
