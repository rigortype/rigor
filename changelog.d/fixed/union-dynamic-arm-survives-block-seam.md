- **[engine]** A variable that may hold either an untyped value or an array — `out = flag ? u : [2]` — no longer loses the untyped half when a block or `while` body appends to it, so a later `out.first.upcase` on correct code stops drawing `call.undefined-method` and `out.first == 3` stops folding to an always-falsey condition; the same fix covers the `Hash` twin and any other non-array arm the variable carries. ([#631](https://github.com/rigortype/rigor/issues/631), [#649](https://github.com/rigortype/rigor/pull/649))
