- **[inference]** A `map` / `flat_map` block over an array literal, or a `transform_values` / `transform_keys` block over a hash whose keys are statically known, no longer reads a value the block mutates in place at its pre-mutation contents when the call sits inside a multi-statement block whose result reads a local that block assigns: after `r = m.synchronize do w = v; { x: [], y: [] }.transform_values { |a| a << w; a } end`, `r` types `{ x: Dynamic[top], y: Dynamic[top] }` instead of `{ x: [], y: [] }`, so `r[:x].first + 1` is no longer reported as a call on `nil`. ([#1213](https://github.com/rigortype/rigor/pull/1213))
  - `select` / `filter` / `reject` over an array literal no longer collapse to an empty array when the block's predicate reads a captured local the block reassigns: after `seen = 0; r = [1, 2].select { |e| seen += 1; seen == 2 }`, `r` types `Array[1 | 2]` instead of `[]`, so `r.size == 0` is no longer reported as always true.
