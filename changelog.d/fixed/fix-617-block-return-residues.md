- **[inference]** Four block-return answers no longer report the value a block started with instead of the one it produced: a mutated counter as a block's tail (`[1, 2].map { total += 1 }`) and a mutated string buffer (`s = +"ab"; s << "c"`) no longer draw a spurious always-truthy warning, `find` / `index` over a counting predicate no longer answer `nil` where Ruby finds a match, and a block that mutates its parameter no longer reports the unmutated value past the nine-element mark.
