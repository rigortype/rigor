- **[inference]** A `map` / `select` / `find` block over an array literal, a `transform_values` / `transform_keys` block over a literal hash, and any other repeating block no longer read a captured array or hash at its pre-loop contents when the block fills one of its elements (`a[0] << e`) or passes it to a method of the same class that mutates it (`add_to(a, e)`), so `a = [[1]]; r = [1, 2].map { |e| v = a[0].size; a[0] << e; v }` stops folding to `[1, 1]` and firing a false always-truthy on `r.last == 1`. ([#1249](https://github.com/rigortype/rigor/pull/1249))
