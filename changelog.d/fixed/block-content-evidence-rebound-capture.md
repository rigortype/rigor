- **[inference]** A block that stores a local it also reassigns — `total += x; out << total`, a block parameter reassigned before it is stored, or the same into an `each_with_object` memo — no longer records that local's value from before the block, so `out` reads `Array[Dynamic[top]]` instead of `Array[0]` and `out.last == 3` no longer reports an always-falsey condition. A value stored at an Array index that reads the index local itself (`ids[n] = n; n += 1`) keeps the earlier reading. ([#1221](https://github.com/rigortype/rigor/pull/1221))
