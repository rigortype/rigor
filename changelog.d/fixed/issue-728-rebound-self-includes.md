- **[types]** A mixin call inside a block that rebinds `self` is no longer attributed to the lexically enclosing class: `Thing = Class.new { include M }` in a class body no longer puts `M`'s methods on that class, `Recv.class_eval { include M }` now records on `Recv`, and a `class << self` include stops reaching the instance surface. ([#728](https://github.com/rigortype/rigor/issues/728), [#749](https://github.com/rigortype/rigor/pull/749))
