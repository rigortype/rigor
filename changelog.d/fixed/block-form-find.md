- **[plugins/rigor-activerecord]** The block form of `find` (`Post.find { |post| post.title == "x" }`, `Post.find(&:published?)`) no longer reports `plugin.activerecord.wrong-arity`, or `call.undefined-method` where the model has an RBS signature. It is `Enumerable#find` over the records, so it types as `Post | nil`, and a relation's `find { … }` now answers the same. [#1327](https://github.com/rigortype/rigor/pull/1327)
