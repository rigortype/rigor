- **[engine]** A `refine X do … end` call where `self` is a class (a `class` body, `class << self`, or a `Class.new` / `Struct.new` / `Data.define` block) is now treated as the class's own method rather than as `Module#refine`, which `Class` does not have. The block's `def`s belong to the class and its body is typed with the class as `self`, instead of being filed as refinements of `X`. ([#1689](https://github.com/rigortype/rigor/issues/1689), [#1745](https://github.com/rigortype/rigor/pull/1745))
