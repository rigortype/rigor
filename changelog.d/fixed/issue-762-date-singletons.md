- **[plugins]** `rigor-activesupport-core-ext` and the bundled ActiveSupport overlay no longer accept `Date.end_of_week`, `Date.beginning_of_month`, `Date.end_of_month`, `Date.beginning_of_year` or `Date.end_of_year`, which ActiveSupport defines only on an instance and which raise `NoMethodError` on the class, and `Date.beginning_of_week` now answers the `Symbol` week start instead of a `Date`. ([#762](https://github.com/rigortype/rigor/issues/762), [#765](https://github.com/rigortype/rigor/pull/765))
