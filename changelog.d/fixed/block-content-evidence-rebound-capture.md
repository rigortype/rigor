- **[inference]** A block that stores a local it also reassigns — `total += x; out << total`, or the same into an `each_with_object` memo — now joins every iteration's value of that local into the collection, so `out` reads `Array[0 | Integer]` instead of `Array[0]` and `out.last == 3` no longer reports an always-falsey condition.
