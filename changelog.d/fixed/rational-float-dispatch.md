- **[inference]** Arithmetic between Ruby's core numbers now types as the class Ruby returns when the argument's class is known and the RBS declares it. `Rational` `+`, `-`, `/`, `modulo`, `remainder` and `quo` by a `Float` type as `Float` rather than `Rational`. `Float` and `Rational` operators with a `Complex` argument type as `Complex` rather than the receiver's class. `Integer#%`, `#modulo`, `#remainder`, `#quo` and `#divmod` by a `Float` or `Rational`, and `Float#%` and `Rational#%`, name that class rather than `Numeric`. An overload the RBS declares for the argument's own class now wins over a receiver's `(Numeric)` overload declared after it. ([#1348](https://github.com/rigortype/rigor/pull/1348))
