- **[inference]** A `rescue` arm and an `ensure` clause now read each local and instance variable the `begin` body rebinds at the values it held wherever the body could raise, instead of only its value before the `begin` (or, for `ensure`, after the body), so `conn = nil; begin; conn = open_conn; …; rescue; conn&.close; end` sees `Conn?` rather than `nil`, and a flag set between two raising calls no longer folds always-falsey in the arm or always-truthy in `ensure`.
