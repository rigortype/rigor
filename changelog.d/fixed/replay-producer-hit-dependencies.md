- **[plugins]** A plugin producer served from its own cache now carries its inputs into the run-result cache and into any producer built on it, so an edit to a file only that producer reads is no longer missed: with rigor-activerecord, a column added to `db/schema.rb` after a model-only edit no longer stays `plugin.activerecord.unknown-column` in `rigor check`, `--workers` and `--incremental` until `--no-cache`. ([#1558](https://github.com/rigortype/rigor/issues/1558), [#1564](https://github.com/rigortype/rigor/pull/1564))
