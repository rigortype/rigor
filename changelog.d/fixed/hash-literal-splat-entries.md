- **[inference]** A hash literal with a `**splat` entry now includes the splatted hash's keys and values in its type, so `o = { a: :z }; h = { **o, b: :y }` types `Hash[:a | :b, :y | :z]` rather than `Hash[:b, :y]`, and `h[:a] == :z` or `h.keys.first == :a` is no longer reported as always falsey; a splat whose contents cannot be read adds `Dynamic[top]` to both. ([#1252](https://github.com/rigortype/rigor/pull/1252))
