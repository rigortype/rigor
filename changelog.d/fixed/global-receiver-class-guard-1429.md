- **[inference]** A class guard now protects the call it guards on a global, constant or local receiver: `$stdout.is_a?(StringIO) ? $stdout.string : nil`, `STDOUT.is_a?(StringIO)`, `$stdout.respond_to?(:string)` and `case io when StringIO then io.string end` no longer report on an `IO`-typed receiver, and a `when` naming a class disjoint from the subject's inferred class is no longer reported unreachable or dropped from the `case` value. Truthiness, `nil?`, `!` and `&.` guards narrow global and constant reads, `respond_to?(:m)` admits `m` on its truthy edge, and a guard's narrowing of a global or constant is restored where a call may run code that rebinds it.
