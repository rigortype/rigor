- **[effects]** A method is now reported under the side of its class that Ruby defines it on: a `def` nested in `def self.outer` and a `define_method` inside a class method are instance methods, while a `define_method` or `attr_accessor` inside `class << self` and a `def` inside `singleton_class.class_eval` or a class body's `instance_eval` are class methods. `rigor effects`, the snapshot and `sig-gen` therefore name them correctly, callers now pick up their effects, and a write to `self` or a `new` in their bodies is judged against the object they really run on. A method defined inside `Class.new`, `Struct.new` or `other.class_eval`, or on a single object, is no longer filed under the enclosing class, where it joined that class's own method of the same name. A committed effect snapshot may need regenerating. [#1316](https://github.com/rigortype/rigor/pull/1316)
