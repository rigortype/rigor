- **[inference]** A method that returns a hash literal with a `**splat` entry, or a `Hash.new` it fills key by key, no longer reports `def.return-type-mismatch` against an RBS record return type, so `def rec = { **BASE, b: 2 }` is accepted for `-> { a: Integer, b: Integer }`; a `Hash[K, V]` whose type arguments are fully known is still reported.
