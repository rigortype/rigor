- **[inference]** A block given to `each` / `map` / `find` / `all?` / `transform_keys` and the other core iterators that updates an outer counter, flag, instance variable, class variable or global no longer has its value typed as if every call saw the first iteration's binding — so `xs.all? { seen += 1; seen == 1 }`, `xs.find { seen += 1; seen == 2 }` and `[1, 2].find { |e| seen ||= 0; (seen += 1) == 2 }` stop drawing always-truthy / always-falsey warnings, and `transform_keys` keeps every key such a block can choose. [#1225](https://github.com/rigortype/rigor/pull/1225)
  - A `break` inside a block that `lambda`, `proc`, `define_method`, `Thread.new`, `Enumerator.new` or `Hash.new` only stores no longer makes that call's result possibly `nil`.
