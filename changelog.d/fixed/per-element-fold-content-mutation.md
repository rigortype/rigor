- **[inference]** A `map` / `select` / `find` block over an array literal no longer reads a captured local hash or array at its pre-loop contents on every element when the block stores into it through an index write or calls a mutating method on the local itself, so `h = { a: 0 }; [:a, :a].map { |k| h[k] = h[k] + 1 }` stops folding to `[1, 1]` and firing a false always-truthy on `r.last == 1`, and `a = [1]; [1, 2].map { a.map!(&:to_s); a.first }` no longer reads `Integer`. ([#1203](https://github.com/rigortype/rigor/pull/1203))
