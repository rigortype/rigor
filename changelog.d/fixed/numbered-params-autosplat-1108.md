- **[inference]** A block that references `_2` or a higher numbered parameter now auto-splats a single yielded array as the equivalent `|a, b|` block does, so `{ 1 => "a" }.each { _1; _2 }` binds the key and value and `ints.each_slice(2) { _1 + _2 }` binds `Integer`; a block using only `_1`, and an `it` block, still receive the whole value, as in CRuby.
