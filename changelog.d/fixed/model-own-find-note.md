- **[plugins/rigor-activerecord]** For a model that defines its own `self.find`, `Post.find(1, 2)` and `Post.find { … }` no longer carry a `plugin.activerecord.model-call` note claiming Rails' `Array[Post]` or `Post | nil`, since the call types as the model's own method, and `Post.find` with no arguments no longer reports `plugin.activerecord.wrong-arity`.
