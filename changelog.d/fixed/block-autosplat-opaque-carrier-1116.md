- **[inference]** A block whose parameter list auto-splats now binds `Dynamic[top]` (or, for a `nil` union member, `nil`) to each position when the yielded value is a carrier Rigor cannot decompose — a raw `Array`, an `Array[untyped]`, or a union with a non-array member — instead of binding the whole value to the first parameter, so `[1, 2].tap { |a, b| a.succ }` and `[[1, "a"], nil].each { |a, b| a.succ if a }` no longer report `undefined method` on a parameter CRuby fills with an element.
