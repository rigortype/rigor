- **[inference]** An in-place mutation called directly on a global, a class variable or the Ruby 3.4 `it` parameter now widens that binding, both in straight-line code and in a block's return value, so `$g = +"k"; r = m.synchronize { $g << v.to_s; $g }` no longer folds `r == "k"` to always-truthy and `[[], []].map { it << 1; it }` no longer types `[[], []]`.
