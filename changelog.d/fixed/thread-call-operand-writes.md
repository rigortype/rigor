- **[inference]** A variable written inside a call's receiver or arguments, an array or hash literal, an interpolation or a `rescue` modifier (`out << (n += 1)`, `puts(g = e)` inside a block) now reaches the code after the statement, so a later comparison no longer folds on the value it held before the write, and a local written in the right operand of an `&&` condition is no longer read as possibly `nil` in the branch that condition guards.
