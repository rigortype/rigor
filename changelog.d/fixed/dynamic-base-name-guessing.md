- **[inference]** A constant written inside a `class_eval` block is now attributed to the class the block runs on, and its value typed with that class as `self`, so `Other.class_eval { self::X = build }` no longer defines an unrelated `X` on the enclosing module nor resolves `build` against it. ([#705](https://github.com/rigortype/rigor/issues/705))
