- **[engine]** A `def` or `attr_*` wrapped in a visibility call (`private def secret = 1`, `private attr_accessor :x`) now takes that call's visibility, and `attr_*` members take the running default, so a call to such a private member from outside the class is now reported by `def.method-visibility-mismatch`; `public def foo` after a bare `private` and a private override of a `private def` are no longer reported. `rigor sig-gen` follows the same reading: it now skips a `private def` / `protected def` by default and emits a `public def` written after a bare `private`. ([#1981](https://github.com/rigortype/rigor/pull/1981))
