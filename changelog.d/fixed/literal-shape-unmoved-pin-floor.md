- **[inference]** A captured array or hash that a `map` / `select` / `find` block reassigns only on a later iteration (`row = [v, v] if count > 3`) no longer reads as its initial value at every position of the result: `sizes.last == 2` over `row = []` stopped folding always-false, at the cost of reading such a variable as untyped whenever a reassignment keeps its type.
