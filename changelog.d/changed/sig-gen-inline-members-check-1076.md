- **[sig-gen]** **BREAKING** — `rigor sig-gen` now writes a method declared inline by `# @rbs` / `#:` into `sig/` by default, as that declaration (a parameter-only annotation keeps its parameters and takes the return from the body; `initialize` is always `-> void`), and a `sig/` declaration that disagrees with the inline one is refused, exiting 1, until the two agree or `--overwrite` replaces the whole `sig/` member; a project whose Steep reads the same annotations (`inline: true` beside `signature "sig"`) must set `sig_gen: { inline_declared: skip }` in `.rigor.yml`, or Steep reports each copied method as `DuplicatedMethodDefinition`. The new `rigor sig-gen --check` exits 1 when `--write` with the same options would change or refuse something in `sig/`, for use as a CI freshness gate. Combining two of `--print`, `--diff`, `--write` and `--check` is now a usage error (exit 64) instead of the last flag silently winning. ([#1422](https://github.com/rigortype/rigor/pull/1422))
