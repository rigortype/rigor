- **[inference]** A module's `def self.included` hook is now read as a possible definer of a singleton method on the class that includes it, as the `extended` and `inherited` hooks already were, so `base.define_singleton_method(:name)` in the hook no longer leaves the inherited `def self.name` typing the call and reporting a false `call.undefined-method`.
