- **[inference]** `case`/`when` and `Class === x` guards now resolve their class name through the enclosing `module` nesting the way `is_a?` already did, and every class guard now resolves a nested path (`x.is_a?(Type::Union)`) rather than reading it as a top-level name — so a guarded receiver keeps its real type instead of decaying to `untyped`, and a `case msg when Monitor` naming your own `Monitor` no longer reports `undefined method` against the stdlib one. ([#635](https://github.com/rigortype/rigor/issues/635))
