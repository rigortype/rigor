- **[engine]** An instance variable with a type in its RBS declaration (`@x: T`, or a typed `attr_reader` / `attr_writer` / `attr_accessor` in `sig/` or inline) now reads that type in place of what its writes suggest, so a declared attribute no longer reads as `untyped` or `nil`, and a declaration looser than the code it describes can surface as diagnostics.
