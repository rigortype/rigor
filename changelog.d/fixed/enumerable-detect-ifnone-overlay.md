- **[inference]** `detect` called with a fallback (`ifnone`) on any Enumerable (a Hash, Range, Set, Struct, Enumerator, IO, …) now answers the fallback as `find` does, instead of `nil` when no element matches: `r = { a: 1 }.detect(-> { 0 }) { |k, v| v > 5 }; r + 1` is no longer reported as a call on `nil`. ([#1274](https://github.com/rigortype/rigor/pull/1274))
  - `detect(nil)`, or any object answering `call` as the fallback, no longer reports `call.argument-type-mismatch`.
  - `all?` / `any?` / `none?` given a pattern no longer fold to the answer of the block Ruby ignores, so `[1, 2].all?(String) { true }` is no longer typed `true` and a condition on it no longer reads as always truthy.
