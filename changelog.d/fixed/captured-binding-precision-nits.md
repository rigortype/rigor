- **[inference]** A block parameter, lambda parameter or block-local that shares a captured local's name, and a local of a `def` written inside a block, no longer count as reassigning the outer local, so `a = [1]; [1, 2].map { |k| [[]].each { |a| a = k }; a.first }` types `[1, 1]` rather than `[Dynamic[top], Dynamic[top]]`, and an escaping block such as `Thread.new { [1].each { |x| x = nil } }` keeps the outer `x`'s narrowing. ([#1279](https://github.com/rigortype/rigor/pull/1279))
