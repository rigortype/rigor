- **[rigor-grape]** New bundled plugin types the `Grape::API` endpoint DSL — `params`/`requires`/`optional` bodies resolve on `Grape::Validations::ParamsScope`, `namespace`/`version`/`route_param` bodies on the `Grape::API::Instance` class object, verb bodies on `Grape::Endpoint`, and `Grape::Entity` `expose` declarations — where every call previously read as `Dynamic[top]`. ([#1099](https://github.com/rigortype/rigor/issues/1099))
  - `Macro::BlockAsMethod` `self_type:` accepts a String naming the `instance_eval` target (`"Grape::Validations::ParamsScope"`, `"singleton(Grape::API::Instance)"`), extending ADR-16 Tier A beyond `:receiver_instance` for DSLs whose blocks run on a different object than the receiver.
