- **[inference]** A `||=` on an instance, class, global or local variable nothing visibly assigned no longer takes its right-hand side as the value when that side can never be truthy: `def self.settings = (@settings ||= raise("boot first"))` reads as whatever set `@settings` rather than `bot`, so `rigor sig-gen` no longer declares `def self.settings: () -> bot`, and `@verbose ||= false` reads `false` or the unseen value instead of `false` alone. A memoizing `@default ||= new` keeps its `App` type. ([#1338](https://github.com/rigortype/rigor/pull/1338))
