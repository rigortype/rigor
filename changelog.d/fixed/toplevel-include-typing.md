- **[engine]** A bare call in a top-level statement now takes the signature of the one RBS module a top-level `include` mixes in, when the project defines no method of that name anywhere, so `crt([2, 3], [3, 5])` after `include AcLibraryRb` reads `[Integer, Integer]` instead of `Dynamic[top]`. It is meant for script-style projects: a mixin onto a receiver no constant names (`base.extend(ClassMethods)` in a `self.included` hook), a computed `define_method` name or a string `eval` anywhere in the project turns it off, and the editor's per-buffer diagnostics and `rigor type-of` do not apply it ([#1715](https://github.com/rigortype/rigor/issues/1715), [#1771](https://github.com/rigortype/rigor/pull/1771)).
