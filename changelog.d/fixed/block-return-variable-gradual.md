- **[inference]** A generic whose block returns a type variable that one of its parameters also names — `Enumerable#sum(init) { … }`, `Enumerable#inject(seed) { … }` on an Enumerator, `Enumerator.produce(initial) { … }` — now leaves that variable untyped instead of taking the block's type as the result, so `s = [1, 2].each.sum(0.0) { |x| x }; s == 3.0` stops folding always-falsey and `(h.sum(0.0) { |_k, v| v } / h.size).nan?` no longer reports `Integer#nan?`. ([#1273](https://github.com/rigortype/rigor/pull/1273))
