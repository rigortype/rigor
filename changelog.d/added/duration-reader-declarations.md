- **[plugins]** `ActiveSupport::Duration`'s reader surface — `ago` / `until` / `since` / `from_now` / `before` / `after`, `to_i` / `in_seconds`, `to_f`, `in_minutes` / `in_hours` / `in_days` / `in_weeks` / `in_months` / `in_years`, `iso8601` and `parts` — is now typed in both rigor-activesupport-core-ext and the auto-applied activesupport overlay, so chains like `30.minutes.ago.iso8601` and `1.day.to_i * 2` resolve past the first reader instead of going opaque ([#632](https://github.com/rigortype/rigor/issues/632)).
