- **[effects]** `new` now counts as a fresh allocation only on a constant, a `class` call, or `self` inside a class method, so a write to the record an ActiveRecord association's `user.posts.new` (or an association extension's bare `new`) builds reads as an `unknown-ownership` taint instead of `mutate.local`, and `rigor effects --pure` and the report no longer list such a method as effect-free (a committed effect snapshot may need regenerating). [#1306](https://github.com/rigortype/rigor/pull/1306)
  - **[effects]** A `new` on a class held in a variable (`klass.new`) is now unproven too, so `sig-gen` withholds a `%a{pure}` it used to emit for a method whose only effect was a write to that object.
