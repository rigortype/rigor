- **[inference]** A method whose RBS return type is `self` now keeps the receiver's type arguments, so `ints.tap { }`, `ints.freeze` or `ints.each { }` on an `Array[Integer]` is `Array[Integer]` and `.first` on the result is `Integer` instead of `Dynamic[top]`; a literal receiver answers its widened nominal (`[1, 2].tap { }` is `Array[Integer]`, `{ a: 1 }.tap { }` is `Hash[Symbol, Integer]`).
