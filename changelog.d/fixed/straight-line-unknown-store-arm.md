- **[inference]** An in-place mutator whose arguments do not describe what it stores — `map!`, `collect!`, a block-form `fill`, `flatten!`, `transform_values!`, `transform_keys!`, `merge!` / `update` and `Hash#replace` — no longer leaves a literal, re-opened or `non-empty-array` / `non-empty-hash` collection with its old element types, so calling a method the rewritten elements define (`a = [1]; a.map!(&:to_s); a.first.upcase`) is no longer reported as `call.undefined-method`, and a literal a hand-written signature pins (`-> Array[:multi]`) is no longer reported as `def.return-type-mismatch` after such a rewrite. ([#1277](https://github.com/rigortype/rigor/pull/1277))
