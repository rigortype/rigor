- **[engine]** A Proc literal refined with Ruby 4.1's `Proc#refined` (`proc { "hi".shout }.refined(Shout)`, likewise `->{}`, `lambda {}` and `Proc.new {}`) now has the given modules' refinements in effect inside its body, including nested blocks and `.refined(A).refined(B)` chains, so refined calls there no longer report `call.undefined-method`. A Proc held in a variable and refined later is not covered. ([#1666](https://github.com/rigortype/rigor/issues/1666), [#1738](https://github.com/rigortype/rigor/pull/1738))
