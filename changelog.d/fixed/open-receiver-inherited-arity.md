- **[engine]** A method name an "open" receiver only inherited — an ActiveRecord scope called `open`, `select` or `format`, which resolves through the relation's ancestry to the `Kernel` method of that name — no longer reports `call.wrong-arity` or `call.argument-type-mismatch` against a signature the call never runs; a method the class declares itself, such as `Relation#limit`, is still checked.
