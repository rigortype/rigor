- **[inference]** `Rational * Float` (for a `Rational` Rigor knows only by class) no longer types as the Float argument's literal: `r * 0.5` is `Float`, not `0.5`, so `(r * 0.5) == 0.5` no longer reports `flow.always-truthy-condition`. The same widening applies to any method whose RBS type variable declares an upper bound, so `(+"ab").setbyte(0, 65)` and `putc(7)` now type as `Integer` rather than their literal, and `rigor sig-gen` writes the class for them. ([#1355](https://github.com/rigortype/rigor/pull/1355))
