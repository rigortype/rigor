- **[rigor sig-gen]** `rigor sig-gen` no longer writes `def self?.x` for a method defined after a bare `public`, `private` or `protected` that follows a bare `module_function`, where Ruby ends the module function mode, now writes `def self?.x` for a module function whose `module_function` follows a bare `private` instead of leaving it out, and skips a method after such a call that may not run (under an `if` or in a block) with the new skip reason `sig.skipped.uncertain-module-function`, counted in the skip summary on stderr. ([#2016](https://github.com/rigortype/rigor/pull/2016))
