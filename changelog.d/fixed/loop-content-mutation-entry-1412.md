- **[inference]** Rigor no longer types a repeating block or loop body from the first iteration's contents of a local the body appends or stores to, so `depth = []; lines.each { |tl| puts depth.last.length if depth.last; depth << tl }` no longer reports `undefined method 'length' for nil`; the same holds for `while` / `until` / `for` bodies. When an iterator's receiver is untyped, a local its block rebinds is read past the first iteration too: a `nil` or `false` placeholder as possibly anything (`names = nil; io.each_line { |l| … names = {} … names[l] = true }`), any other value as its class (`count = 0` as `Integer`, so `count.upcase` still reports). A read that only the first iteration makes of an appended collection or of such a placeholder is no longer checked. [#1441](https://github.com/rigortype/rigor/pull/1441)
