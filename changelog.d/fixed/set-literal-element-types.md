- **[inference]** `Set[x, y]` and `Set.new(array)` over non-constant members now carry their element type (`Set[Array[Symbol]]`, `Set[String]`) instead of `Set[Dynamic[top]]`, `.freeze` and `.dup` keep it, and `Set.new(enum) { ... }` no longer reads the block-less elements as the set's, so `rigor sig-gen` proposes a reader over a frozen Set constant as `Set[untyped]` rather than skipping it ([#2278](https://github.com/rigortype/rigor/issues/2278)).
