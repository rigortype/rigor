- **[inference]** An in-place mutator used as the receiver of another call, an argument or a literal element now widens the variable it mutates exactly as it does as a statement, so `d.map!.with_index { |x, i| x.to_s }; d.first.upcase` no longer reports a false `call.undefined-method` for Integer, and `b.push(2).size` no longer leaves `b` typed as its `[1]` literal.
