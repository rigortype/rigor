- **[plugins]** `rigor-ffi` reads `./Gemfile.lock` and `ext/**/extconf.rb` through its `IoBoundary` for its `:ffx` / `:ffi` target. Before this, when one of those files changed with no source edit, `rigor check --incremental` and a cached `rigor check` reused the previous diagnostics and missed `plugin.ffi.ffx.unsupported-*`. Plugins get `IoBoundary#glob` for a recursive pattern. ([#1652](https://github.com/rigortype/rigor/issues/1652), [#1802](https://github.com/rigortype/rigor/pull/1802))
