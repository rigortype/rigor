- **[inference]** `transform_values` / `transform_keys` over a hash literal no longer read a captured local the block reassigns at its first-iteration value at every key: `total = 0; { x: 1, y: 2 }.transform_values { total += 1 }` now types `{ x: Integer, y: Integer }` instead of `{ x: 1, y: 1 }`, so a later `r[:y] == 1` is no longer reported as always true.
