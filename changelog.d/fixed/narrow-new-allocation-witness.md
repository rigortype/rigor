- **[effects]** A `new` called on anything other than a class written as a constant, `self` or `self.class` — an ActiveRecord association's `user.posts.new`, or a class held in a variable — no longer counts as a fresh allocation, so a write to the object it returns reads as an `unknown-ownership` taint instead of `mutate.local`, and `rigor effects --pure` and `sig-gen`'s `%a{pure}` stop treating such a method as effect-free (a committed effect snapshot may need regenerating).
