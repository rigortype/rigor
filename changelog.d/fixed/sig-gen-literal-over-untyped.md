- **[sig-gen]** Over a `-> untyped` declared in `sig/`, `rigor sig-gen` now writes a `true` or `false` return as bool and keeps `untyped` over a return that is only `nil`, so a subclass override no longer reports `def.override-return-widened` on correct code, and a Range literal is written as `Range[Integer]` (or `Range[untyped]`) rather than a bare `Range` that `rbs validate` rejects. ([#2069](https://github.com/rigortype/rigor/pull/2069))
