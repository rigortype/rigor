- **[inference]** A hash literal with a `**splat` entry now includes the splatted hash's keys and values in its type, so `o = { a: :z }; h = { **o, b: :y }` types `Hash[:a | :b | Dynamic[top], :y | :z | Dynamic[top]]` rather than `Hash[:b, :y]`, and `h[:a] == :z` or `h.keys.first == :a` is no longer reported as always falsey; a key written into such a literal afterwards (`h = { **o, b: 2 }; h[:c] = 3; h[:c] == 3`) is no longer read as missing either. ([#1252](https://github.com/rigortype/rigor/pull/1252))
