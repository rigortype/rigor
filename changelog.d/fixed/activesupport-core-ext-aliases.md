- **[sig]** The bundled ActiveSupport overlay and the `rigor-activesupport-core-ext` plugin now declare `Object#deep_dup`, `Hash#with_defaults` / `#with_defaults!` / `#reverse_update`, `Hash#to_options` / `#to_options!`, `Hash#extract!`, `Hash#deep_merge?`, `Hash#nested_under_indifferent_access`, `Range#overlaps?` and `Range#to_fs` / `#to_formatted_s`, so `[[1], [2]].deep_dup` and `(a..b).overlaps?(c..d)` no longer report a false `call.undefined-method`. `Hash#reverse_merge` also keeps the argument's keys and values in its result type instead of answering the receiver's own.
