- **[inference]** A named `module_function :x` on a name the module inherits (for example `module Kernel; include KHelp; module_function :kx` in a `pre_eval` file) now records the public singleton copy Ruby makes, so `Kernel.kx` no longer reports `call.undefined-method`; the private instance side is unchanged, and a later `private_class_method :x` or `private :x` in `class << self` makes the copy private as Ruby does.
