- **[plugins]** A bundled plugin's RBS no longer collides with a signature you supply yourself: when `rbs collection install` (or your own `sig/`) declares a class the plugin also declares, but with a different number of generic parameters, the plugin's declaration steps aside instead of failing the definition build — previously `rigor-activerecord` and the collection's `activerecord` each declared `ActiveRecord::Relation` at a different arity, so every call into a relation silently read `Dynamic[top]` on a run that exited 0. ([#610](https://github.com/rigortype/rigor/issues/610))
