- **[check]** A method a class defines itself is checked again where an `include` elsewhere in its ancestry is conditional, written in a hook or reached twice: `call.wrong-arity`, the override and visibility lints and a pattern match on the class's own `deconstruct` no longer stay silent there, because no `include` can shadow the class's own definition; a hook or a concern block that may `prepend` onto the class still silences them. A project module declared with nothing in it is no longer treated as an unknown ancestor that may define any method. In `--incremental` runs, a class whose own method answers a check is re-checked when its superclass gains a hook that may prepend onto it.
