- **[inference]** A memoizing index `||=` inside a block that runs more than once — `cache = {}; [1, 2].find { |e| (cache[:first] ||= e) == 2 }` — no longer reads each run's own value as if the slot were empty, so `find` answers `1 | 2 | nil` instead of `2` and `found == 2` no longer reports a false `flow.always-truthy-condition`. This holds whatever the receiver (a captured hash or array, an instance or class variable, a constant, an attribute reader, a nested memo), while a memo whose key differs at every element keeps its precise type.
