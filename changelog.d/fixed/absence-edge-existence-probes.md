- **[plugins]** A plugin that checks whether a project file or directory exists before reading it — `config/sidekiq.yml`, `config/recurring.yml`, an `app/models` discovery root — now records that check as a cache dependency, so the next `rigor check` re-analyzes once the file or directory appears (or disappears) instead of serving the answer computed while it was missing. ([#613](https://github.com/rigortype/rigor/issues/613), [#641](https://github.com/rigortype/rigor/pull/641))
