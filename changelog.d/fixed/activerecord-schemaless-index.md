- **[plugins]** `rigor-activerecord` no longer switches itself off on a project that ships raw migrations without a committed `db/schema.rb` — it now types table names, finders, scopes and associations from the model source alone and stands down only the column-dependent checks, disclosing the reduced mode at `info` instead of `warning`.
