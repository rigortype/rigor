- **[inference]** Rigor no longer types a block's rebound counter or flag from its first iteration when the receiver is untyped or a project class outside its iterator catalogue, so it no longer reports `items.all? { |x| seen += 1; seen == 1 }` on an untyped `items`, or `find` on a project class that includes `Enumerable`, as always truthy or always falsey. A project method that merely shares an iterator's name (`def select(key) = yield(key)`) is still typed as running its block once. A project class whose ancestry reaches `Enumerable` or a core collection now keeps a block's rebinds after the call, as an `Array` does, so Rigor may newly report `call.possible-nil-receiver` on a local that stays `nil` when the collection is empty (`label = nil; shelf.each_with_index { |e, _i| label = e }; label.upcase`).
