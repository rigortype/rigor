- **[engine]** A `rescue => @err` or `for @x in` write in one method no longer leaves a sibling method's `if @err` / `@x == 0` folding on the constructor's value, and `for *a in`, `for *@a in`, `for *@@a in` and `for *$a in` bind their variable. ([#3202](https://github.com/rigortype/rigor/pull/3202))
  - The class instance-variable seed now includes those writes: a rescue reference with the exception class the clause names, a `for` index as unknown. The class-variable seed includes a rescue reference or `for` index write as unknown.
  - `rescue => @@err` and `for @@x in` bind the class variable, and a bare splat `for` index binds its variable to the element's array, so a later read no longer reports `flow.always-truthy-condition` on the pre-loop value.
