- **[engine]** A `rescue => @err` or `for @x in` write in one method no longer leaves a sibling method's `if @err` / `@x == 0` folding on the constructor's value, and `for *a in` binds `a`. ([#3202](https://github.com/rigortype/rigor/pull/3202))
  - The class instance-variable and class-variable seeds now include those writes: a rescue reference with the exception class the clause names, a `for` index as unknown.
  - `rescue => @@err` and `for @@x in` bind the class variable, and `for *a in pairs` binds `a` to the element's array, so a later read no longer reports `flow.always-truthy-condition` on the pre-loop value.
