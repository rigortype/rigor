- **[rbs-extended]** The PHPStan-style integer range `int<min, max>` in a `%a{rigor:v1:…}` payload is deprecated in favour of the Ruby range spelling `Integer[min..max]`; it still resolves, and every annotation that uses it now reports `dynamic.rbs-extended.deprecated-form` (`info`) naming the spelling to write. The alias is removed at the next compatibility break ([ADR-109](https://github.com/rigortype/rigor/blob/master/docs/adr/109-ruby-native-range-notation.md), [#854](https://github.com/rigortype/rigor/pull/854)).
