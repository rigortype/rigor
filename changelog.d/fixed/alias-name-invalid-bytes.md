- **[inference]** `alias_method "\xff", :x` (or a class-body macro naming a method with bytes no Symbol can hold) no longer aborts the file with an `EncodingError` internal analyzer error. Such a name now reads as a computed one, so no alias is recorded and the rest of the file is analysed. ([#1821](https://github.com/rigortype/rigor/issues/1821), [#1825](https://github.com/rigortype/rigor/pull/1825))
