- **[sig-gen]** The handbook documents a `# sig-gen gap: #NNN — reason` RBS comment convention for recording a declaration `rigor sig-gen` cannot produce — a `tighter-return` you decided not to apply, a skipped method, a declaration with no `def` behind it — so a hand-written type in `sig/` carries a pointer to the engine work that would replace it instead of being indistinguishable from one nobody has revisited.
