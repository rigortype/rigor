- **[config]** A new `test_paths:` key declares where the project's tests live (several directories allowed; unset auto-detects `spec/` and `test/`), and `rigor sig-gen --params=observed` now observes those roots instead of only `spec/`, so a Minitest project's `test/` types parameters without `--observe`. `rigor init` writes the roots it finds, and sig-gen says on stderr when there is no root to observe or a declared one does not exist.
