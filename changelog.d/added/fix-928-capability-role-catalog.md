- **[rbs]** Rigor now ships the capability-role interfaces its specification names — `_Closable`, `_RewindableStream`, `_ClosableStream`, `_FileDescriptorBacked` and `_Callable` — as bundled RBS, so a `%a{rigor:v1:conforms-to _ClosableStream}` directive resolves and is actually checked with no configuration; a project declaring an interface of the same name keeps its own, and a directive naming an interface that does not exist is now a warning instead of an info. ([#976](https://github.com/rigortype/rigor/pull/976))
