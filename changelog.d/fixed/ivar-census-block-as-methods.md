- **[engine]** An instance-variable write inside a plugin-declared route block (`get "/" do @user = "alice" end` under rigor-sinatra, which now also covers `before` / `after` filters and `error` / `not_found` handlers) counts toward the class's instance-variable typing, so a sibling method no longer reports a call on `nil` for an ivar `initialize` or another route sets to `nil`; as for a `def` writer, an RBS-declared non-nil reader of such an ivar can now report `def.return-type-mismatch`.
