- **[inference]** A block parameter that receives the receiver (`Object#tap` yields `self`) now carries the receiver's type arguments through the same `-> self` substitution verdict the return path applies, so `ints.tap { |a| }` binds `a` to `Array[Integer]` instead of a raw `Array`, and `[1, 2].tap { |a, b| }` binds the pinned element union `1 | 2` per slot with the optimistic mark rather than `Dynamic[top]`; an element-changing mutator still keeps the raw nominal.
