- **[engine]** A module function's instance copy is now recorded private, as Ruby makes it, so a class that includes a `module_function` module and overrides one of its methods privately no longer reports `def.override-visibility-reduced`, and `rigor sig-gen` no longer writes a public `def x` for `module_function :x` or `module_function def x` (it emits that private method only with `--include-private`). ([#2055](https://github.com/rigortype/rigor/pull/2055))
