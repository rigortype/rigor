- **[engine]** Gem source inference (`dependencies.source_inference:`) now treats a `def` inside a gem's `refine String do … end` as a refinement, so `"hi".shout` after `using` the gem's module no longer reports `call.undefined-method`. The method is also no longer filed as a method of the refining module. ([#1672](https://github.com/rigortype/rigor/issues/1672), [#1686](https://github.com/rigortype/rigor/pull/1686))
