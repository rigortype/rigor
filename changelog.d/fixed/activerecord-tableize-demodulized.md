- **[plugins]** `rigor-activerecord` now resolves a namespaced model's table the way Rails actually does — `Blog::Post` reads `posts`, dropping the namespace, with a prefix or suffix applied only when the enclosing module declares one — instead of flattening the namespace into the name (`blog_posts`), which had silently disabled that model's column, alias and association checks whenever the guessed table did not exist. ([#623](https://github.com/rigortype/rigor/issues/623))
