- **[incremental]** `rigor check --incremental` now stays warm on projects using rigor-sidekiq, rigor-rails-i18n or rigor-rails-routes: the plugin fact surface is digested by value, so a producer served from the cache no longer reads as changed. Before, the null run after priming and every run after an edit reported "plugin fact surface changed" and ran a full analysis; on Mastodon an edit took about 21 s instead of about 2 s. ([#1574](https://github.com/rigortype/rigor/issues/1574), [#1577](https://github.com/rigortype/rigor/pull/1577))
