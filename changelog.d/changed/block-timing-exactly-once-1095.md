- **[inference]** `tap`, `then` and `yield_self` call their block exactly once before returning, so a block that never completes normally no longer leaves the receiver in the call's type: `[1, 2].tap { break "s" }` is `"s"` and `[1, 2].tap { raise "x" }` is `bot`. A receiver whose class defines its own `tap` / `then` keeps the previous answer. ([#1105](https://github.com/rigortype/rigor/pull/1105))
