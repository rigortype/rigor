- **[rigor check]** A `.rbs` that declares the same method twice — typically a project `sig/` carrying a copy of a signature Rigor already bundles — is now reported as the `rbs.coverage.definition-build-failed` warning, so a class that silently lost its whole method surface (and took every call on it down to `Dynamic[top]`) is visible in `--format json`, SARIF, CI annotations and the LSP instead of only as a line on stderr; the `reject-unparseable-signatures` bleeding-edge feature promotes it to an error ([#696](https://github.com/rigortype/rigor/issues/696)).
